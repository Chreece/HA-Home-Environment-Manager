# HEM - 家庭環境管理者

<p align="center">
  <img src="../../.github/assets/hem-logo.svg" alt="HEM ロゴ" width="420">
</p>

<p align="center"><strong>家庭の環境を一つに Home Assistant カード</strong></p>

**HEM 部屋の周りを理解し 部屋のニーズに 反応する助けになります** それはあなたの Home Assistant センサー,天気データ,居住情報,兼容的な気候装置を組み合わせて,空気の質を監視し,有用な通気アドバイスを受け,快適さを管理し,選択した機器を自動化することができます.

例えば HEM 部屋の暖房を減らしたり,帰宅前に 部屋の湿度を 調整したり,寝ている間に 湿度を 異なる標的にしたり, 脱湿器を動かす前に 窓を開けるとしたりできます. **監視と推奨**装置を制御することなく

**お前が指揮を続ける** 各部屋には独自の設定があり,各サポートされた機器には独自のコントローラー,操作モード,ターゲット,安全制限があります. HEM デバイスを選択することで,そのデバイスを操作する許可を与えると仮定しない.

[特徴を探求する](#what-can-hem-do) · [インターフェースを見る](#see-hem-in-action) · [HEMを設置する](#installation) · [家を作れ](#getting-started) · [詳細なガイド](../../docs/advanced-configuration.md)

<a id="what-can-hem-do"></a>
## 何ができるのか HEM やってる?

| あなたの状況 | どのようにして HEM 役に立たない |
| --- | --- |
| **家は空いている** | 対象をオフに切り替えて 各部屋の存在規則を尊重し 選択された機器を不必要に操作しないようにします |
| **帰る途中だ** | 押す **到着を準備する** 対象となる自動制御器に 家庭コンフォートターゲットを一時的に使用する |
| **誰かが寝ている** | 寝る 目的 を 活用 し,扇風機 の 騒音 を 減らす こと,または 部屋 の 部屋 の 寝る 場所 が 居 て いる 時 に 選択 さ れ た デバイス を 消す こと. |
| **一室は湿っています** | 標的に示された湿度と模様を比較し,有用な空気を提案し,自動または PID 制御する |
| **暑くて晴れてる** | 部屋温,太陽光,天気,接続された窓コンタクトを,選択した色を移動する前に評価する. |
| **屋外空気が良く見える** | 室内需要,室外汚染,温度,湿度,風力,利用可能な花粉や気象警告を用いた通風を推奨する. |
| **暖房機やTRVは反応を停止する** | バッテリーまたはリレーが回復したと仮定せずに,利用できない状態または待機状態を表示し,設定されたコントローラを保持し,サポートされたデバイスの故障を報告します. |

行動ではなく HEM 選択したセンサーに 基づいて Home Assistant 機能と オプトイン設定.

<a id="explore-the-features"></a>
## 特徴を探求する

<a id="a-complete-home-dashboard"></a>
### 完全なホームダッシュボード

労働組合 HEM カードは,複数の統合を開く必要なく,有用な概要を提供します.

- 屋外環境,空気の質,空気の通風が適切かどうか確認してください.
- 監視された部屋をすべて一目で見てみてください. 温度,相対湿度, AQI, PM2.5,模具表示,光および他のサポートされた測定値.
- 詳細な測定,窓とドア情報,気候状態,アクティブコントローラ,待機理由,建物物理学的推定のための空間を拡大する.
- 歴史と傾向を見て,どのセンサーが平均に貢献したかを見て,測定値から欠落した読み方を区別してください.
- グループルーム Home Assistant 床がない場合 シンプルな部屋のリストを使用します

<a id="different-settings-for-the-home-each-room-and-each-device"></a>
### 家庭,各部屋,各装置の設定が異なります

HEM 共有された政策を地方の決定から切り離します.

| 設定レベル | 設定できるもの |
| --- | --- |
| **家庭** | 室外の気象と汚染源,監視された部屋,世界の通気制限,家庭の存在,到着準備と通知の配達. |
| **部屋** | 室内温度と湿度源,空気の質の限界値,窓と扉の接触,睡眠と占拠の行動,部屋のコンフォート目標,換気と遮蔽の選択肢. |
| **個々の装置** | 制御モードは,自動/手動/PID メソッド,プロフィールごとにターゲット,センサー,静かなファン設定,最小動作時間,電源保護,ウィンドウ行動,デバイスエラー通知. |

3 つのレベルは,カード内のグループ化された,検索可能な設定を通じてアクセスできます.必要なときに,日常の設定を混ぜずに,高度な制御が利用できます. Home Assistant 設定変更

<a id="climate-control-and-pid-device-by-device"></a>
### 気候変動対策と PID装置ごとに

HEM 互換性のある Home Assistant **気候**, **ハウミディファイト** そして **扇風機** 暖房,冷却,脱湿,湿気化および空気循環または空気清浄装置を含む装置.

各 **サポートされている物理操作モード**制御方法を独立して選択する

| 方法 | その意味 |
| --- | --- |
| **現存する** | 既存のコントローラ経路で操作を停止する |
| **自動化** | フォローする HEM状況に基づいた目標と許可を測定する |
| **PID** | 装置と測定がそれを支える場合,フィードバックベースの比例的,統合的および衍生制御を使用する. |
| **手動** | 明確に支持された要求や目標による制御. |
| **消す** | 制御器をオフにして下さい 物理的な保護とフィードバックの要求に準拠します |

例えば,1つの空調機は **PID 暖房用** そして **自動冷却**脱湿器には独自の装置がある PID カリブレーション,ターゲット,サイクルタイムリング. PID 適切なフィードバックと目的の特定制御が利用可能である場合.

PID は **はい** 普遍的なオーバーリード: HEM 動作モードとフィードバックソースがサポートできる方法のみが提供されます.先進オプションには,モードごとに調節と校正,推奨/適応調整,静かな動作およびサポートされたステージファンの設定が含まれます.制限された自動適応を明確に選択しない限り,提案された変更を承認します.

<a id="comfortable-when-youre-home-economical-when-youre-away"></a>
### 快適で家にいる時 遠ざかっている時 経済的

HEM 選択できる **快適さ,家,遠方,眠り,環境** 家庭状況,部屋の証拠,そしてあなたの明示的な選択に基づいた目標を設定します

- **家庭と旅:** 確認された自宅の存在に応じて,異なる加熱,冷却,湿度目標を使用します.
- **部屋の存在:** 適格なデバイスを常に需要がある時,部屋が占められている時,または部屋が空いている時のみ実行します.
- **睡眠** 夜間の標的と静かなファン行動を適用します 選択したデバイスは,すべての部屋が眠っているときにオフに留まります.
- **エコ:** 設定された場合,経済的な目標を使用します. 部屋が空いていると確認され,他の条件が満たされた場合,閉ざされた室内ドアが保護されたエコポリシーに参加することができます. 閉ざされたドアだけでは部屋が孤立していることを証明しません.
- **覚醒準備:** アラームの前に自動睡眠を放置し,応募可能なデバイスに応答する時間を与えるために,設定された次のアラーム源を使用します.

占用量,装置の利用可能性,または他の必要な証拠が不確実である場合 HEM 自動装置を起動することは安全だと仮定するだけでは不十分です.

<a id="prepare-your-environment-before-you-arrive"></a>
### 到着する前に環境を準備する

**到着を準備する** カードヘッダーから起動します. HEM家庭装置だ

HEM 設定された設定を一時的に適用する **家庭目標** 対象となる自動/PID コントローラーを設置し,部屋が暖かしたり冷やしたり,帰還前に湿度を調整したりできます.これは,通常は占拠された部屋に限定された コントローラーを一時的に許可することも可能です. **必要な物理制御許可が既に取得された場合のみ**.

準備はすべてをオンにする命令ではありません.デバイスは依然として本物の需要,有効なセンサー,許可が必要です.そして,窓,最小のオン/オフ時間,および独自の保護を尊重する必要があります. 誰かが到着するとアクションが終了します,あなたはそれをキャンセルします,または設定されたタイマーが終了します. Home Assistant 再起動はフルタイマーを再起動しません.

<a id="ventilation-advice-windows-doors-and-shading"></a>
### 換気,窓,ドア,シェイディングに関するアドバイス

HEM 比較する **部屋に必要なもの** と **屋外空気が役立つかどうか**.

- 窓を開けるか閉じるかを推奨し,室内での現在の測定,室外の湿度,汚染,温度,風,気象予報およびオプションの花粉コンテキストを使用する.
- 部屋の条件を説明するために,選択された窓とドアコンタクトを使用し,未知のコンタクトを閉ざされたものと扱うのを避ける.
- 選択的にサポートされた自動機器を起動する前に窓を開くようにお願いします. 必要に応じて設定された応答が待ってから正常な制御を続けます.
- 部屋の境界意識,通気注意事項,選択的に保護されたエコ行動のためのドア情報を使用します.
- 適切な窓,温度,天気,太陽の上昇とオプションの照明の証拠を使用して選択されたシャッター,レンズ,シェイドを管理する.

HEM 制御可能な窓なしの通風のアドバイスを 与えることができます 窓を開けることは 単に空気が助かるためではありません

<a id="humidity-mold-indication-and-air-quality"></a>
### 湿度,模具表示と空気の質

HEM サポートされた読み取りを組み合わせる **温度,湿度,CO2,粒子,VOC, AQIおよび照明** 各部屋を理解するのに役立ちます. Home Assistant 設定の提供.

その **模具の表示** 室内および室外温度および校准測定から冷たい表面の湿度条件を推定する.適切に設定された場合,サポートされた自動湿度制御器の効果的な標的に影響を与えることができます.

**模具の表示は推定で 模具やスポーラ検出器ではありません** 欠落または時代遅れなセンサーデータは,新しい模様ベースのデバイスコマンドを正当化することはできません.

<a id="announcements-diagnostics-and-protection"></a>
### 公告,診断,保護

設定された Home Assistant 通知,TTS/メディアプレーヤーまたは **広告ハブ**AIはメッセージの表現を変えることができます HEM物理的なコントロールの決定は 決定的なままです

HEM また,デバイス特有の保護と診断を含む.

- 最低のオンとオフ期間,最大の動作時間設定およびサポートされた外部電源スイッチ操作.
- 窓と占拠制限,マニュアル・オーバーライド操作,ネイティブコマンド確認チェック
- 誤りおよび不可用デバイスの報告,各デバイスの通知行動の選択.
- 停電命令後,疑わしい継続的な加熱のために,保護された監視と限られた回復試みを伴う,シャットダウン後のオプションの監視犬.
- 待機理由や 現在の運用状況や ソースの利用可能性が明確で 制御を可能にする前に調べることができます

**警報が無効になった場合でも 安全制限は有効です** HEM 装置が物理的に応答した証拠として 成功したコマンド発送を扱わない.

<a id="getting-started"></a>
## スタートする

1. **部屋を整理する** 中 Home Assistant各区域に適切なセンサーと装置を割り当てます
2. **監視するものを選択する** 追加する HEM部屋の温度,湿度,窓,空気の質,装置の源をチェックして,使用されていないグループを空にしておくことができます.
3. **共有された情報を設定する.** 屋外の気象/空気の品質の情報源,家庭用占拠の証拠,そしてあなたが望む広告目的地を選択してください.
4. **カードを追加する** 編集モードでダッシュボードを開いて **家庭環境管理者** 部屋のモニタリング,読み取り,通風のアドバイスから始めましょう
5. **制御を有効にする** 部屋を開いて,サポートされた装置を選択し,そのコントローラをチェックし, PID あなたが望むモードのために HEM 操作する

分かってる **はい** 各部屋にスマートな装置が必要です センサーから始め 一度に自動制御装置を導入します

<a id="add-the-card-manually"></a>
### 手動でカードを追加する

統合は通常,独自のLovelaceカードを登録します.YAMLを好む場合は:

~~~yaml
type: custom:home-environment-manager-card
~~~

あなたの Home Assistant 装置は1つ以上 HEM 推奨センサーを設定し,適切な **事業所** 明らかに:

~~~yaml
type: custom:home-environment-manager-card
entity: sensor.your_hem_recommendation_sensor
~~~

部屋の源,プロフィール, PID 準備,模具の校正,太陽光遮光と発表の配達, [詳細な構成ガイド](../../docs/advanced-configuration.md).

<a id="installation"></a>
## 設置

<a id="hacs--home-assistant-community-store"></a>
### HACS / Home Assistant コミュニティショップ

1. オープン **HACS** 中 Home Assistant.
2. 追加する **[http://github.com/Chreece/HA-Home-Environment-Manager]** とする **カスタムリポジトリ** 中には **統合** リストに記載されていない場合のカテゴリー
3. 探す **家庭環境管理者** そしてそれをインストールする.
4. 再起動 **Home Assistant** 統合を充電する
5. 行って **設定 → デバイス & サービス → 統合を追加**検索する **家庭環境管理者** そして,設定を完了します.

<a id="manual-installation"></a>
### 手動の設置

資料庫のコピー **custom_components/environment_manager** パッケージをマッチングに **構成要素** リストの Home Assistant 設定,ディレクトリ名を保持する **環境_管理者**再起動する Home Assistant 統合を追加する **設定 → デバイスとサービス**.

設置変更については,既存の HEM ブラウザのダッシュボードがすぐに刷新されない場合,再充電します.

<a id="common-questions"></a>
## 一般的な質問

**使ってもいいですか? HEM 私のデバイスを 制御することなく?**

監視,測定,換気に関するアドバイス,歴史,多くの環境指標は 装置のアクチュエーションを有効にせずに動作します

**ウィル HEM 発見する全てのデバイスを自動制御する?**

サポートされているモードの制御方法を明確に選択し,センサーの資格とネイティブデバイスの機能がまだ何が可能かを決定します.

**すべての機器がサポートしている PID?**

違うわ HEM 支援 PID について **対象となる** 装置と選択された測定が必要な能力とフィードバックを提供する場合,加熱,冷却,湿度または扇風機制御経路. PID 制御する

**各部屋に別々のルールがあるか?**

居場所,睡眠習慣,情報源,標的,そして安全性設定は各部屋によって異なりますが,各デバイスには独自の操作と保護設定があります.

**出来る HEM 私がいない間に家を準備する?**

- そうだ **到着を準備する** 対象となる自動コントローラーが 限定期間でホームターゲットを使用することを一時的に許可します. 物理的な保護を回避したり,目標達成を保証したりしません.

**窓を開けるのに 換気剤の良いおすすめがあるか?**

自動移動は,自己安全チェックの対象となる資格のあるサポートされたシェードやカバーの別のオプション機能です.

**センサーやデバイスが利用できない場合は?**

HEM 自動制御には,有効な現在の権限と証拠が必要です.
