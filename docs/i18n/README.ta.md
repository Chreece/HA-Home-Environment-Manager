# HEM - வீட்டு சுற்றுச்சூழல் மேலாளர்

<p align="center">
  <img src="../../.github/assets/hem-logo.svg" alt="HEM லோகோ" width="420">
</p>

<p align="center"><strong>உங்கள் வீட்டின் முழு சுற்றுச்சூழலும், ஒரு Home Assistant அட்டை.</strong></p>

**HEM உங்கள் வீடு அதன் சூழலைப் புரிந்துகொள்ளவும், ஒவ்வொரு அறைக்கும் உண்மையில் என்ன தேவை என்பதை உணரவும் உதவுகிறது.** அது உங்கள் கொண்டு Home Assistant சென்சார்கள், வானிலை தரவு, ஆக்கிரமிப்புத் தகவல் மற்றும் இணக்கமான காலநிலை சாதனங்கள் ஒன்றாக இணைந்து நீங்கள் காற்று தரத்தை கண்காணிக்க முடியும், பயனுள்ள காற்றோட்டம் ஆலோசனைகளைப் பெறலாம், வசதியை நிர்வகிக்கலாம் மற்றும் நீங்கள் தேர்ந்தெடுத்த உபகரணங்களை தானியங்குபடுத்தலாம்.

உதாரணமாக, HEM எல்லோரும் வெளியே இருக்கும்போது வெப்பத்தை குறைக்கலாம், நீங்கள் திரும்புவதற்கு முன் தேர்ந்தெடுக்கப்பட்ட அறைகளை தயார் செய்யலாம், நீங்கள் தூங்கும் போது வேறு ஈரப்பத இலக்கைப் பயன்படுத்தலாம் அல்லது ஒரு ஈரப்பதமூட்டி இயங்கும் முன் ஒரு ஜன்னலைத் திறக்கக் கேட்கலாம். **கண்காணித்தல் மற்றும் பரிந்துரைத்தல்**, எந்த சாதனத்தையும் கட்டுப்படுத்தாமல்.

**நீங்கள் தலைமை நீடிக்கும்.** ஒவ்வொரு அறைக்கும் அதன் சொந்த அமைப்புகள் உள்ளன. ஆதரிக்கப்படும் ஒவ்வொரு சாதனத்திற்கும் அதன் சொந்த கட்டுப்பாட்டாளர், இயக்க முறைமைகள், இலக்குகள் மற்றும் பாதுகாப்பு வரம்புகள் உள்ளன. HEM ஒரு சாதனத்தைத் தேர்ந்தெடுப்பது, அதை இயக்குவதற்கு அனுமதி அளிக்கிறது என்று ஒருபோதும் கருதுவதில்லை.

## என்ன செய்ய முடியும் HEM செய்வதா?

| உங்கள் நிலைமை | எப்படி HEM உதவ முடியும் |
| --- | --- |
| **வீடு காலியாக உள்ளது** | இலக்குகளை விலக்கிக் கொள்ளவும், ஒவ்வொரு அறையின் இருப்பின் விதிமுறைகளை மதிக்கவும், தேர்ந்தெடுக்கப்பட்ட உபகரணங்களை தேவையற்ற முறையில் இயக்குவதைத் தவிர்க்கவும். |
| **நீ வீட்டிற்குப் போகிறாய்** | அழுத்தவும் **வருவதற்கு தயாராக இருங்கள்** தகுதி பெற்ற தானியங்கி கட்டுப்பாட்டாளர்களுக்கான வீட்டு வசதி இலக்குகளை தற்காலிகமாகப் பயன்படுத்தவும், எல்லோரும் இன்னும் தொலைவில் இருந்தாலும். |
| **யாராவது தூங்குகிறார்கள்** | தூக்க இலக்குகளைப் பயன்படுத்தவும், ரசிகர் சத்தத்தைக் குறைக்கவும், அல்லது ஒவ்வொரு அறைகளும் தூங்கும் போது தேர்ந்தெடுக்கப்பட்ட சாதனங்களை அணைக்கவும். |
| **ஒரு அறை ஈரமாக உள்ளது** | அதன் ஈரப்பதம் மற்றும் அச்சு குறிப்பை இலக்குகளுடன் ஒப்பிடுங்கள், பயனுள்ள காற்றோட்டம் பரிந்துரைக்கவும் அல்லது தானியங்கி அல்லது PID கட்டுப்பாடு. |
| **அது சூடாகவும் சூரியனுமாகவும் இருக்கிறது** | தேர்ந்தெடுக்கப்பட்ட நிழல்களை மாற்றுவதற்கு முன் அறை வெப்பநிலை, சூரிய ஒளி, வானிலை மற்றும் இணைக்கப்பட்ட ஜன்னல் தொடர்புகளை மதிப்பிடுங்கள். |
| **வெளிப்புற காற்று சிறப்பாக தெரிகிறது** | உட்புற தேவை, வெளிப்புற மாசுபாடு, வெப்பநிலை, ஈரப்பதம், காற்று மற்றும் கிடைக்கும் தூள் அல்லது வானிலை எச்சரிக்கைகள் ஆகியவற்றைப் பயன்படுத்தி காற்றோட்டம் செய்ய பரிந்துரைக்கவும். |
| **ஒரு ஹீட்டர் அல்லது டிஆர்வி விடைகொடுப்பதை நிறுத்துகிறது** | ஒரு பேட்டரி அல்லது ரிலே மீட்கப்பட்டதாக கருதாமல், அதன் கிடைக்காத அல்லது காத்திருக்கும் நிலையை காண்பி, அதன் கட்டமைக்கப்பட்ட கட்டுப்பாட்டாளரை வைத்திருங்கள் மற்றும் ஆதரிக்கப்பட்ட சாதனத் தவறுகளை தெரிவிக்கவும். |

இவை உதாரணங்கள், செயல்கள் அல்ல HEM ஒவ்வொரு வீட்டிலும் உள்ள சக்திகள். முடிவுகள் உங்கள் தேர்ந்தெடுக்கப்பட்ட சென்சார்கள், ஒவ்வொரு சாதனத்தின் உண்மையான Home Assistant திறன்கள் மற்றும் உங்கள் விருப்ப அமைப்புகளை.

## அம்சங்களை ஆராயுங்கள்

<a id="a-complete-home-dashboard"></a>
### ஒரு முழுமையான வீட்டு டாஷ்போர்டு

பீ. HEM அட்டை பல ஒருங்கிணைப்புகளைத் திறக்காமல் பயனுள்ள கண்ணோட்டத்தை உங்களுக்கு வழங்குகிறது.

- வெளிப்புற நிலைமைகள், காற்றின் தரம் மற்றும் காற்றோட்டம் பரிந்துரைக்கப்படுகிறதா என்பதைப் பார்க்கவும்.
- கண்காணிக்கப்படும் அனைத்து அறைகளையும் ஒரே பார்வையில் ஒப்பிட்டுப் பாருங்கள்ஃ வெப்பநிலை, உறவினர் ஈரப்பதம், AQI, PM2.5, அச்சு குறிப்பு, ஒளி மற்றும் பிற ஆதரிக்கப்பட்ட வாசிப்புகள்.
- விரிவான அளவீடுகள், ஜன்னல் மற்றும் கதவு தகவல், காலநிலை நிலை, செயலில் உள்ள கட்டுப்பாட்டாளர்கள், காத்திருப்பு காரணங்கள் மற்றும் கட்டிட-உயிரியல் மதிப்பீடுகள் ஆகியவற்றிற்கான எந்த இடத்தையும் விரிவுபடுத்துங்கள்.
- வரலாறுகள் மற்றும் போக்குகளைப் பார்க்கவும், எந்த சென்சார்கள் சராசரியாக பங்களித்தன என்பதைப் பார்க்கவும், அளவிடப்பட்ட மதிப்புகளிலிருந்து காணாமல் போன வாசிப்புகளை வேறுபடுத்தவும்.
- குழு அறைகள் Home Assistant தரைகள், அல்லது தரைகள் இல்லாதபோது ஒரு எளிய அறை பட்டியலைப் பயன்படுத்தவும்.

<a id="different-settings-for-the-home-each-room-and-each-device"></a>
### வீடு, ஒவ்வொரு அறை மற்றும் ஒவ்வொரு சாதனத்திற்கும் வெவ்வேறு அமைப்புகள்

HEM பகிரப்பட்ட கொள்கைகளை உள்ளூர் முடிவுகளிலிருந்து பிரித்து வைத்திருக்கிறது.

| அமைப்புகள் நிலை | நீங்கள் அமைக்க முடியும் என்ன |
| --- | --- |
| **வீடு** | வெளிப்புற வானிலை மற்றும் மாசுபாடு ஆதாரங்கள், கண்காணிக்கப்பட்ட அறைகள், உலகளாவிய காற்றோட்டம் வரம்புகள், வீட்டுவசதி இருப்பு, வருகைத் தயாரிப்பு மற்றும் அறிவிப்பு வழங்கல். |
| **அறை** | உட்புற வெப்பநிலை மற்றும் ஈரப்பதம் ஆதாரங்கள், காற்று தர வாசல்கள், ஜன்னல் மற்றும் கதவு தொடர்புகள், தூக்கம் மற்றும் ஆக்கிரமிப்பு நடத்தை, அறைக்கு குறிப்பிட்ட வசதி இலக்குகள், காற்றோட்டம் மற்றும் நிழல் தேர்வுகள். |
| **தனிப்பட்ட சாதனம்** | அதன் இயங்குதல் முறைகள், தானியங்கி/கையேடு/PID முறை, ஒரு சுயவிவரத்திற்கான இலக்குகள், சென்சார்கள், அமைதியான விசிறி அமைப்புகள், குறைந்தபட்ச இயக்க நேரம், மின்சார பாதுகாப்பு, ஜன்னல் நடத்தை மற்றும் சாதன பிழை அறிவிப்புகள். |

மூன்று நிலைகளும் அட்டையில் குழுமப்படுத்தப்பட்ட, தேடக்கூடிய அமைப்புகளின் மூலம் அணுகக்கூடியவை. தேவைப்படும்போது மேம்பட்ட கட்டுப்பாடுகள் உள்ளன, அன்றாட அமைப்புகளை நெரிசல் செய்யாமல். Home Assistant அமைப்பு மாற்றங்கள்.

### காலநிலை கட்டுப்பாடு மற்றும் PID, சாதனத்திற்கு சாதனம்

### நீங்கள் வீட்டில் இருக்கும்போது வசதியாக இருக்கும், நீங்கள் வெளியே இருக்கும்போது பொருளாதாரமாக இருக்கும்

HEM தேர்வு செய்யலாம் **ஆறுதல், வீடு, தூக்கம் மற்றும் சுற்றுச்சூழல்** வீட்டு நிலைமை, அறை சான்றுகள் மற்றும் உங்கள் வெளிப்படையான தேர்வுகளின் அடிப்படையில் இலக்குகள்.

- **வீடு மற்றும் புறம்ஃ** வீட்டில் சரிபார்க்கப்பட்ட இருப்பைப் பொறுத்து வெப்பம், குளிரூட்டல் மற்றும் ஈரப்பதம் ஆகியவற்றின் வெவ்வேறு இலக்குகளை பயன்படுத்தவும்.
- **அறை இருப்பைஃ** ஒரு தகுதிவாய்ந்த சாதனத்தை எப்போது வேண்டுமானாலும் இயக்கவும், அதன் அறை ஆக்கிரமிக்கப்பட்டிருக்கும் போது மட்டுமே அல்லது அறை காலியாக இருக்கும்போது மட்டுமே.
- **தூக்கம்:** இரவு நேர இலக்குகள் மற்றும் அமைதியான விசிறி நடத்தை பயன்படுத்தவும். தேர்ந்தெடுக்கப்பட்ட சாதனம் அனைத்து அறைகளும் தூங்கும் போது அணைக்கப்படலாம்.
- **சுற்றுச்சூழல்ஃ** கட்டமைக்கப்பட்ட இடங்களில் பொருளாதார இலக்குகளைப் பயன்படுத்தவும். ஒரு மூடிய உட்புற கதவு அறையை வெற்று மற்றும் பிற நிபந்தனைகள் பூர்த்தி செய்யப்பட்டால் பாதுகாக்கப்பட்ட சுற்றுச்சூழல் கொள்கையில் பங்கேற்க முடியும்; ஒரு மூடிய கதவு மட்டுமே அறையை தனிமைப்படுத்தியுள்ளது என்பதை நிரூபிக்காது.
- **விழிப்புணர்வுக்கான தயாரிப்புஃ** விழிப்புணர்வைத் தொடங்குவதற்கு முன் தானியங்கி தூக்கத்தை விட்டுவிடவும், தகுதி பெற்ற சாதனங்களுக்கு பதிலளிக்க நேரம் கொடுக்கவும் ஒரு அமைக்கப்பட்ட அடுத்த அலாரம் மூலத்தைப் பயன்படுத்தவும்.

பயன்பாடு, சாதனத்தின் கிடைக்கும் தன்மை அல்லது பிற தேவையான ஆதாரங்கள் நிச்சயமற்றதாக இருந்தால், HEM ஒரு தானியங்கி சாதனத்தை இயக்குவது பாதுகாப்பானது என்று கருதுவது மட்டுமல்ல.

### நீங்கள் வருவதற்கு முன் உங்கள் சூழலை தயார் செய்யுங்கள்

**வருவதற்கு தயாராக இருங்கள்** இது ஒரு உறுதிப்படுத்தப்பட்ட தொலைதூர வீட்டிற்கு ஒரு காலக்கெடு நடவடிக்கை. அதை அட்டை தலைப்பில் இருந்து தொடங்குங்கள் அல்லது HEMஅது வீட்டு சாதனம்.

HEM தற்காலிகமாக அமைக்கப்பட்ட பொருந்தும் **வீட்டு இலக்குகள்** தகுதி பெற்ற தானியங்கி/PID கட்டுப்பாட்டாளர்கள் நீங்கள் திரும்பி வருவதற்கு முன் அறைகள் வெப்பமடைதல், குளிர்வித்தல் அல்லது ஈரப்பதத்தை சரிசெய்வதற்கு உதவும். இது ஒரு கட்டுப்பாட்டாளரை தற்காலிகமாக அனுமதிக்கும். **இதற்கு தேவையான உடல் கட்டுப்பாட்டு அனுமதி கிடைத்தால் மட்டுமே**.

தயாரிப்பு என்பது எல்லாவற்றையும் இயக்க ஒரு கட்டளை அல்ல. சாதனங்களுக்கு இன்னும் உண்மையான தேவை, செல்லுபடியாகும் சென்சார்கள் மற்றும் அங்கீகாரம் தேவை, மேலும் ஜன்னல்கள், குறைந்தபட்ச ON / OFF நேரங்கள் மற்றும் அவற்றின் சொந்த பாதுகாப்புகளை மதிக்க வேண்டும். யாராவது வரும்போது நடவடிக்கை முடிவடைகிறது, நீங்கள் அதை ரத்து செய்கிறீர்கள், அல்லது கட்டமைக்கப்பட்ட டைமர் காலாவதியாகிறது. Home Assistant மறுதொடக்கம் முழு நேரத்தை மீண்டும் தொடங்காது.

### காற்றோட்டம், ஜன்னல்கள், கதவுகள் மற்றும் நிழல்

HEM ஒப்பிடுகிறது **ஒரு அறைக்கு என்ன தேவை** உடன் **வெளிப்புற காற்று உதவ முடியுமா**.

- தற்போதைய உட்புற அளவீடுகள், வெளிப்புற ஈரப்பதம், மாசுபாடு, வெப்பநிலை, காற்று, வானிலை எச்சரிக்கைகள் மற்றும் விருப்பமான தூள் சூழலைப் பயன்படுத்தி ஜன்னல்களைத் திறக்கவும் அல்லது மூடவும் பரிந்துரைக்கவும்.
- தேர்ந்தெடுக்கப்பட்ட ஜன்னல் மற்றும் கதவு தொடர்புகளைப் பயன்படுத்தி அறை நிலைமைகளை விளக்குங்கள் மற்றும் அறியப்படாத தொடர்புகளை மூடப்பட்டதாகக் கருதாதீர்கள்.
- ஒரு ஆதரவு தானியங்கி சாதனத்தைத் தொடங்குவதற்கு முன் ஒரு ஜன்னலைத் திறக்க முயற்சிக்கவும், பின்னர் தேவைப்பட்டால் உள்ளமைக்கப்பட்ட பதில் காத்திருக்கும் போது இயல்பான கட்டுப்பாட்டைத் தொடரவும்.
- அறை எல்லைகளை உணர்ந்து கொள்ள, காற்றோட்டம் எச்சரிக்கைகள் மற்றும் விருப்பமாக பாதுகாக்கப்பட்ட சுற்றுச்சூழல் நடத்தை ஆகியவற்றிற்காக கதவு தகவலைப் பயன்படுத்தவும்.
- பொருத்தமான ஜன்னல், வெப்பநிலை, வானிலை, சூரியன் உயர்வு மற்றும் விருப்பமான விளக்கு ஆதாரங்களைப் பயன்படுத்தி தேர்ந்தெடுக்கப்பட்ட சாளரங்கள், திரைக்காட்சிகள் மற்றும் நிழல்களை நிர்வகிக்கவும்.

HEM எந்த கட்டுப்படுத்தக்கூடிய ஜன்னல்களும் இல்லாமல் காற்றோட்ட ஆலோசனைகளை வழங்க முடியும். காற்றோட்டம் உதவுவதால் மட்டுமே அது ஒரு ஜன்னலைத் திறக்காது.

### ஈரப்பதம், அச்சு குறிப்பு மற்றும் காற்றுத் தரம்

HEM ஆதரவு வாசிப்புகளை சேர்க்கிறது **வெப்பநிலை, ஈரப்பதம், CO2, துகள்கள், VOC, AQI மற்றும் விளக்கு** ஒவ்வொரு அறையையும் புரிந்து கொள்ள உதவும். Home Assistant அமைப்பை வழங்குகிறது.

அதன் **அச்சு குறிப்பு** அறை மற்றும் வெளிப்புற வெப்பநிலையிலிருந்து ஒரு குளிர்ந்த மேற்பரப்பில் ஈரப்பத நிலைகளை மதிப்பிடுகிறது மற்றும் ஒரு அளவீட்டு அளவீடு. இது சரியாக கட்டமைக்கப்பட்டால், ஆதரிக்கப்படும் தானியங்கி ஈரப்பத கட்டுப்பாட்டாளரின் பயனுள்ள இலக்கை பாதிக்கும்.

**மோல்ட் குறிப்பு என்பது மதிப்பீடு, மோல்ட் அல்லது ஸ்போர் கண்டறிதல் அல்ல.** காணாமல்போன அல்லது காலமற்ற சென்சார் தரவுகள் ஒரு புதிய அச்சு அடிப்படையிலான சாதன கட்டளையை நியாயப்படுத்த முடியாது.

<a id="announcements-diagnostics-and-protection"></a>
### அறிவிப்புகள், நோயறிதல் மற்றும் பாதுகாப்பு

நீங்கள் உள்ளமைக்கப்பட்ட வழியாக பொருத்தமான பரிந்துரைகள் மற்றும் எச்சரிக்கைகளை அனுப்ப முடியும் Home Assistant அறிவிப்புகள், TTS/மீடியா பிளேயர்கள் அல்லது **அறிவிப்பு மையம்**ஒரு செய்தியை எவ்வாறு ஒழுங்குபடுத்தப்படுகிறது என்பதை AI மாற்ற முடியும்; HEMஉடல் கட்டுப்பாட்டு முடிவுகள் உறுதியானவை.

HEM மேலும் சாதன-குறிப்பிட்ட பாதுகாப்பு மற்றும் நோயறிதல் ஆகியவை அடங்கும்ஃ

- குறைந்தபட்ச ON மற்றும் OFF காலங்கள், அதிகபட்ச இயக்க நேரம் அமைப்புகள் மற்றும் ஆதரிக்கப்படும் வெளிப்புற சக்தி-சன்னிப்பு கையாளுதல்.
- விண்டோஸ் மற்றும் ஆக்கிரமிப்பு கட்டுப்பாடுகள், கையேடு மீறல் கையாளுதல் மற்றும் உள்ளூர் கட்டளை அங்கீகாரம் சோதனைகள்.
- ஒவ்வொரு சாதனத்திற்கும் அறிவிப்பு நடத்தை தேர்ந்தெடுப்பதன் மூலம் பிழை மற்றும் கிடைக்காத சாதன அறிக்கை.
- மூடலுக்குப் பிறகு ஒரு விருப்பமான கண்காணிப்பு நாய், மூடல் கட்டளைக்குப் பிறகு தொடர்ந்து வெப்பமயமாக்கப்படுவதாக சந்தேகிக்கப்படுகிறது, பாதுகாக்கப்பட்ட கண்காணிப்பு மற்றும் வரையறுக்கப்பட்ட மீட்பு முயற்சிகள்.
- தெளிவான காத்திருப்பு காரணங்கள், தற்போதைய செயல்பாட்டு நிலை மற்றும் ஆதாரங்கள் கிடைப்பது, எனவே நீங்கள் அதிக கட்டுப்பாட்டை இயக்குவதற்கு முன் ஆய்வு செய்யலாம்.

**எச்சரிக்கை செயலிழந்தாலும் பாதுகாப்பு வரம்புகள் தொடர்ந்து செயல்படுகின்றன.** HEM ஒரு சாதனம் இயற்பியல் ரீதியாக பதிலளித்ததற்கான ஆதாரமாக ஒருபோதும் ஒரு வெற்றிகரமான கட்டளை அனுப்புதலை கருதுவதில்லை.

<a id="getting-started"></a>
## தொடங்குதல்

1. **உங்கள் அறைகளை ஒழுங்கமைக்கவும்.** உள்ள Home Assistant, உங்கள் பகுதிகளை உருவாக்கவும் அல்லது சரிபார்க்கவும், ஒவ்வொருவருக்கும் பொருத்தமான சென்சார்கள் மற்றும் சாதனங்களை ஒதுக்கவும்.
2. **எதை கண்காணிக்க வேண்டும் என்பதைத் தேர்ந்தெடுக்கவும்.** சேர்க்கவும் HEM, நீங்கள் விரும்பும் அறைகளைத் தேர்ந்தெடுத்து பரிந்துரைக்கப்பட்ட வெப்பநிலை, ஈரப்பதம், ஜன்னல், காற்று தரம் மற்றும் சாதன ஆதாரங்களை மறுபரிசீலனை செய்யுங்கள். நீங்கள் பயன்படுத்தப்படாத குழுக்களை காலியாக விடலாம்.
3. **பகிரப்பட்ட தகவலை அமைக்கவும்.** வெளிப்புற வானிலை / காற்று தர ஆதாரங்களைத் தேர்ந்தெடுக்கவும், வீட்டு வசதி சான்றுகள் மற்றும் நீங்கள் விரும்பும் அறிவிப்பு இடங்களைத் தேர்ந்தெடுக்கவும்.
4. **அட்டை சேர்க்கவும்.** ஒரு டாஷ்போர்டை திருத்த பயன்முறையில் திறந்து **வீட்டு சுற்றுச்சூழல் மேலாளர்** அட்டை. அறை கண்காணிப்பு, வாசிப்பு மற்றும் காற்றோட்டம் ஆலோசனை தொடங்குங்கள்.
5. **பயனுள்ள இடத்தில் மட்டுமே கட்டுப்பாட்டை இயக்குங்கள்.** ஒரு அறையைத் திறந்து, ஒரு ஆதரிக்கப்பட்ட சாதனத்தைத் தேர்ந்தெடுத்து, அதன் கட்டுப்பாட்டாளரைப் பார்க்கவும் மற்றும் வெளிப்படையாக தானியங்கி அல்லது PID நீங்கள் விரும்பும் முறைகளுக்கு HEM செயல்பட.

நீங்கள் செய்ய **இல்லை** ஒவ்வொரு அறையிலும் ஒரு ஸ்மார்ட் சாதனம் தேவை. உங்களிடம் உள்ள சென்சார்கள் மூலம் தொடங்கி, ஒரு நேரத்தில் ஒரு இயந்திரத்தை இயக்குவதை அறிமுகப்படுத்துங்கள்.

<a id="add-the-card-manually"></a>
### கைமுறையாக அட்டையை சேர்க்கவும்

ஒருங்கிணைப்பு வழக்கமாக அதன் சொந்த லவ்லேஸ் அட்டையை பதிவு செய்கிறது. நீங்கள் YAML ஐ விரும்பினால், பயன்படுத்தவும்ஃ

~~~yaml
type: custom:home-environment-manager-card
~~~

உங்கள் Home Assistant நிறுவல் ஒன்றுக்கு மேற்பட்டது HEM பரிந்துரை சென்சார், நீங்கள் பொருத்தமான அமைக்க வேண்டும் **நிறுவனம்** வெளிப்படையாகஃ

~~~yaml
type: custom:home-environment-manager-card
entity: sensor.your_hem_recommendation_sensor
~~~

அறையின் ஆதாரங்கள், சுயவிவரங்கள், PID அமைப்புகள், ஜன்னல் கொள்கைகள், தயாரிப்பு, அச்சு அளவீடு, சூரிய நிழல் மற்றும் அறிவிப்பு வழங்கல், [விரிவான கட்டமைப்பு வழிகாட்டி](../../docs/advanced-configuration.md).

## நிறுவல்

<a id="hacs--home-assistant-community-store"></a>
### HACS / Home Assistant சமூக கடை

1. திறந்த **HACS** உள்ள Home Assistant.
2. சேர்க்கவும் **https://github.com/Chreece/HA-Home-Environment-Manager** ஒரு **தனிப்பயனாக்கப்பட்ட களஞ்சியம்** உள்ள **ஒருங்கிணைப்பு** ஏற்கனவே பட்டியலிடப்படவில்லை என்றால் வகை.
3. கண்டுபிடிக்க **வீட்டு சுற்றுச்சூழல் மேலாளர்** மற்றும் அதை நிறுவ.
4. மறுதொடக்கம் **Home Assistant** ஒருங்கிணைப்பை ஏற்ற.
5. செல்ல **அமைப்புகள் → சாதனங்கள் & சேவைகள் → ஒருங்கிணைப்பைச் சேர்க்கவும்**, தேடல் **வீட்டு சுற்றுச்சூழல் மேலாளர்** மற்றும் அமைப்பை முடிக்க.

### கையேடு நிறுவல்

காப்புரிமையின் நகல் **custom_components/environment_manager** பொருந்தக்கூடிய அடைவில் **custom_components** உங்கள் பட்டியலில் Home Assistant தொகுப்பு, அடைவு பெயரை வைத்திருக்கும் **environment_manager**. மறுதொடக்கம் Home Assistant மற்றும் ஒருங்கிணைப்பு மூலம் சேர்க்க **அமைப்புகள் → சாதனங்கள் & சேவைகள்**.

அடுத்தடுத்த நிறுவல் மாற்றங்களுக்கு, உங்கள் இருக்கும் HEM ஒருங்கிணைப்பு நுழைவு மற்றும் அமைப்புகள். உங்கள் உலாவியில் உள்ள டாஷ்போர்டை உடனடியாக புதுப்பிக்கவில்லை என்றால் அட்டையின் தோற்றம்.

<a id="common-questions"></a>
## பொதுவான கேள்விகள்

**நான் பயன்படுத்த முடியுமா HEM என் சாதனங்கள் கட்டுப்பாட்டை கொடுக்காமல்?**

ஆமாம். கண்காணிப்பு, அளவீடுகள், காற்றோட்டம் ஆலோசனைகள், வரலாறு மற்றும் பல சுற்றுச்சூழல் குறிப்புகள் சாதனத்தை செயல்படுத்தாமல் செயல்படுகின்றன.

**வில் HEM தானாக ஒவ்வொரு சாதனத்தையும் கட்டுப்படுத்த?**

இல்லை. நீங்கள் நிர்வகிக்க விரும்பும் இயற்பியல் சாதனங்களைத் தேர்ந்தெடுத்து, ஆதரிக்கப்படும் பயன்முறைகளுக்கான கட்டுப்பாட்டு முறையை வெளிப்படையாகத் தேர்ந்தெடுக்கிறீர்கள். சென்சார் தகுதி மற்றும் சொந்த சாதன திறன்கள் இன்னும் என்ன சாத்தியம் என்பதை தீர்மானிக்கின்றன.

**ஒவ்வொரு சாதனமும் ஆதரிக்கிறதா PID?**

இல்லை. HEM ஆதரவு PID க்கான **தகுதி** வெப்பமாக்கல், குளிர்வித்தல், ஈரப்பதம் அல்லது விசிறி கட்டுப்பாட்டு பாதைகள், சாதனம் மற்றும் தேர்ந்தெடுக்கப்பட்ட அளவீடுகள் தேவையான திறன்களையும் பின்னூட்டத்தையும் வழங்கும் போது. ஆதரிக்கப்படாத முறைகள் செயற்கை முறையில் கொடுக்கப்படவில்லை PID கட்டுப்பாடு.

**நான் ஒவ்வொரு அறைக்கும் வித்தியாசமான விதிகள் கொடுக்க முடியுமா?**

ஆமாம். ஆக்கிரமிப்பு நிலைமைகள், தூக்க நடத்தை, ஆதாரங்கள், இலக்குகள் மற்றும் சில பாதுகாப்பு விருப்பத்தேர்வுகள் அறைக்கு ஏற்ப வேறுபடலாம், அதே நேரத்தில் ஒவ்வொரு இயற்பியல் சாதனத்திற்கும் அதன் சொந்த செயல்பாட்டு மற்றும் பாதுகாப்பு அமைப்புகள் உள்ளன.

**முடியும் HEM நான் வெளியே இருக்கும் போது என் வீடு தயார்?**

ஆம். **வருவதற்கு தயாராக இருங்கள்** தகுதியான, ஏற்கனவே அங்கீகரிக்கப்பட்ட தானியங்கி கட்டுப்பாட்டாளர்கள் குறிப்பிட்ட காலத்திற்கு வீட்டு இலக்குகளை பயன்படுத்த அனுமதிக்கப்படுகிறார்கள். இது உடல் பாதுகாப்புகளைத் தவிர்க்காது அல்லது இலக்கை அடைய உத்தரவாதம் அளிக்காது.

**என் ஜன்னல்களை காற்றோட்டத்திற்கு ஏற்ற பரிந்துரை திறக்கிறதா?**

இல்லை. காற்றோட்டம் எப்போது உதவக்கூடும் என்பதை இது விளக்குகிறது. தானியங்கி இயக்கம் என்பது தகுதிவாய்ந்த ஆதரவு நிழல்கள் அல்லது மூடிகளுக்கு தனி, விருப்ப அம்சமாகும், இது அவர்களின் சொந்த பாதுகாப்பு சோதனைகளுக்கு உட்பட்டது.

**ஒரு சென்சார் அல்லது சாதனம் கிடைக்கவில்லை என்றால் என்ன செய்வது?**

HEM அறியப்படாத தரவுகளை உண்மையான வாசிப்புகளிலிருந்து வேறுபடுத்துகிறது, முடிந்தால் கட்டமைக்கப்பட்ட கட்டுப்பாட்டுக் கண்காணிப்பாளர் தகவலை வைத்திருக்கிறது மற்றும் காத்திருப்பு காரணங்கள் மற்றும் நோயறிதல்களை வெளிப்படுத்துகிறது. தானியங்கி கட்டுப்பாடு இன்னும் செல்லுபடியாகும் தற்போதைய அதிகாரத்தையும் ஆதாரத்தையும் தேவைப்படுகிறது.

## உதவி மற்றும் பிழைத் தீர்வு

ஏதேனும் தவறு இருந்தால், தொடர்புடைய அறை அல்லது கட்டுப்பாட்டாளரின் **காரணம்**, **நோயறிதல்**, மூல கிடைக்கும் தன்மை மற்றும் தற்போதைய கட்டுப்பாட்டு முறை. [விரிவான கட்டமைப்பு வழிகாட்டி](../../docs/advanced-configuration.md) பொதுவான காத்திருப்பு நிலைகள், வருகைக் கொள்கைகள் ஆகியவற்றை உள்ளடக்கியது. PID தகுதி, விண்டோஸ் மற்றும் சாதன பதில் சிக்கல் தீர்வு.

ஒரு மறுபடியும் நிகழக்கூடிய பிரச்சனைக்கு, [ஒரு திறக்க GitHub வெளியீடு](https://github.com/Chreece/HA-Home-Environment-Manager/issues) எதிர்பார்த்த நடத்தை, உண்மையான நடத்தை, பொருத்தமான அறை / சாதன அமைப்புகள் மற்றும் இனப்பெருக்கம் செய்ய வேண்டிய படிகள். பதிவுகள் மற்றும் படங்களில் இருந்து தனியார் தகவல்களை அகற்றவும்.

பங்களிப்புகள் மற்றும் மேம்பாடுகள் வரவேற்கப்படுகின்றன. [பங்களிப்பு.md](../../CONTRIBUTING.md).
