# HEM - ผู้จัดการสิ่งแวดล้อมบ้าน

<p align="center">
  <img src="../../.github/assets/hem-logo.svg" alt="HEM ล็อกโอ" width="420">
</p>

<p align="center"><strong>สิ่งแวดล้อมของบ้านของคุณทั้งหมด ในหนึ่ง Home Assistant บัตร</strong></p>

**HEM ช่วยให้บ้านเข้าใจสิ่งแวดล้อม และตอบสนองกับสิ่งที่ห้องละห้องต้องการจริงๆ** มันทําให้คุณ Home Assistant เซนเซอร์ข้อมูลอากาศ ข้อมูลการใช้งาน และอุปกรณ์อากาศที่เหมาะสมด้วยกัน เพื่อให้คุณสามารถติดตามคุณภาพของอากาศ ได้รับคําปรึกษาด้านการลมหายใจ ที่มีประโยชน์ การบริหารความสะดวกสบาย และอัตโนมัติอุปกรณ์ที่คุณเลือก

ตัวอย่างเช่น HEM สามารถลดความร้อนได้ในขณะที่ทุกคนอยู่ห่างออกไป เตรียมห้องที่คัดเลือกก่อนที่คุณจะกลับมา ใช้เป้าหมายความชื้นที่แตกต่างกันในขณะที่คุณนอน หรือขอให้คุณเปิดหน้าต่างก่อนเปิดเครื่องตัดความชื้น **ติดตามและแนะนํา**โดยไม่ควบคุมอุปกรณ์ใดๆ

**เจ้าอยู่หัว** ทุกห้องมีการตั้งค่าของตัวเอง ทุกอุปกรณ์ที่สนับสนุน มีการควบคุมของตัวเอง รูปแบบการทํางาน เป้าหมายและขอบเขตความปลอดภัย HEM ไม่เคยคิดว่าการเลือกอุปกรณ์จะอนุญาตให้ใช้อุปกรณ์นั้น

## อะไรสามารถ HEM ทํายังไง?

| สถานการณ์ของคุณ | วิธีการ HEM ช่วยได้ |
| --- | --- |
| **บ้านว่างเปล่า** | เปลี่ยนไปยัง เป้าหมายไปข้างนอก การปฏิบัติตามกฎการมีตัวของห้องละห้อง และหลีกเลี่ยงการใช้อุปกรณ์ที่คัดเลือกอย่างไม่จําเป็น |
| **คุณกําลังกลับบ้าน** | กด **เตรียมตัวมาถึง** เพื่อใช้เป้าหมายความสบายใจในบ้านชั่วคราว สําหรับเครื่องควบคุมอัตโนมัติที่มีสิทธิ์ แม้ว่าทุกคนยังอยู่ห่าง |
| **มีใครบางคนหลับ** | ใช้เป้าหมายการนอนหลับ ลดเสียงแฟน หรือปิดอุปกรณ์ที่เลือกไว้ ในขณะที่ทุกห้องที่มีคนนอนหลับ |
| **ห้องหนึ่งมีความชื้น** | เปรียบเทียบความชื้นและอักษรอ่อนของมันกับเป้าหมาย, แนะนําการอากาศที่มีประโยชน์, หรือทํางาน dehumidifier ที่ได้รับอนุญาต โดยใช้อัตโนมัติหรือ PID การควบคุม |
| **มันร้อนและมีแดด** | การประเมินอุณหภูมิห้อง, แสงแดด, สภาพอากาศและการติดต่อหน้าต่างที่เชื่อมต่อ ก่อนย้ายสีที่เลือก |
| **อากาศภายนอกดูดีขึ้น** | แนะนําการลมผ่านการใช้ความต้องการในภายในห้อง, การสบายภายนอก, อุณหภูมิ, ความชื้น, ลม และการเตือนฝุ่นหรืออากาศที่มีอยู่ |
| **เครื่องทําความร้อนหรือ TRV หยุดตอบสนอง** | แสดงสถานการณ์ที่ไม่สามารถใช้ได้ หรือรอคอย, รักษาเครื่องควบคุมที่ตั้งไว้ และรายงานความผิดพลาดของอุปกรณ์ที่สนับสนุนโดยไม่คิดว่าแบตเตอรี่หรือสลับได้ฟื้น |

นี่เป็นตัวอย่าง ไม่ใช่การกระทําที่ HEM ส่งผลขึ้นอยู่กับเซ็นเซอร์ที่คุณเลือก Home Assistant ความสามารถและการตั้งค่าการเลือกเข้าของคุณ

## ค้นหาลักษณะ

<a id="a-complete-home-dashboard"></a>
### แดชบอร์ดบ้านครบครัน

สาขา HEM การ์ดจะให้คุณเห็นภาพรวมที่ใช้ได้โดยไม่ต้องเปิดอินเทรคเทอร์หลายตัว

- ดูสถานการณ์ภายนอก คุณภาพอากาศ และการอากาศที่ควร
- เปรียบเทียบห้องทั้งหมดที่ติดตามด้วยการดู: อุณหภูมิ, ความชื้นส่วนตัว, AQI, PM2.5, การแสดงอวัยวะ, แสงและการอ่านที่สนับสนุนอื่น ๆ
- เติมพื้นที่ใด ๆ สําหรับการวัดรายละเอียด ข้อมูลหน้าต่างและประตู สถานการณ์สภาพอากาศ ผู้ควบคุมที่ทํางาน เหตุผลการรอและประมาณการฟิสิกส์อาคาร
- ดูประวัติศาสตร์และแนวโน้ม ดูเซนเซอร์ใดที่ส่งผลต่อค่าเฉลี่ย และแยกค่าที่ขาดจากค่าที่วัด
- ห้องกลุ่มตามตัวจริง Home Assistant หรือใช้รายชื่อห้องง่ายๆ เมื่อไม่มีพื้น

<a id="different-settings-for-the-home-each-room-and-each-device"></a>
### การตั้งค่าที่แตกต่างกันสําหรับบ้าน ทุกห้องและเครื่อง

HEM รักษานโยบายที่แบ่งแยกจากการตัดสินใจในพื้นที่

| ระดับการตั้งค่า | สิ่งที่คุณสามารถตั้งค่า |
| --- | --- |
| **บ้าน** | อากาศภายนอกและแหล่งปรับมลพิษ ห้องติดตาม ขั้นขอบเขตการลมหายากระดับโลก ความมีอยู่ของครัวเรือน การเตรียมการเดินทางและการจัดส่งประกาศ |
| **ห้อง** | แหล่งอุณหภูมิและความชื้นภายในห้อง, ณ ระดับคุณภาพของอากาศ, ติดต่อหน้าต่างและประตู, การนอนและพฤติกรรมในการใช้งาน, เป้าหมายความสะดวกสบายเฉพาะห้อง, การรับอากาศและการเลือกเงา. |
| **เครื่องเฉพาะตัว** | รูปแบบการควบคุมที่ใช้ได้ อัตโนมัติ/มือPID วิธีการ, เป้าหมายต่อโปรไฟล์, เซ็นเซอร์, การตั้งค่าแฟนเงียบ, เวลาทํางานขั้นต่ํา, การป้องกันไฟฟ้า, การพฤติกรรมหน้าต่างและแจ้งความผิดพลาดของอุปกรณ์ |

ทั้งสามระดับสามารถเข้าถึงได้ผ่านการตั้งค่าที่แบ่งกลุ่มและสามารถค้นหาได้ในบัตร การควบคุมที่ทันสมัยสามารถเข้าถึงได้เมื่อจําเป็น โดยไม่ต้องยุ่งเรืองการตั้งค่าประจําวัน คุณสามารถอัพเดทตัวเลือกแหล่งได้ Home Assistant การเปลี่ยนแปลงการตั้งค่า

<a id="climate-control-and-pid-device-by-device"></a>
### การควบคุมอากาศและ PID, เครื่องต่อเครื่อง

HEM สามารถทํางานกับ Home Assistant **สภาพอากาศ**, **เครื่องชื้น** และ **แฟน** อุปกรณ์รวมถึงอุปกรณ์ทําความร้อน, เย็นเย็น, เคล็ดความชื้น, เคล็ดความชื้น และอุปกรณ์ทําความสะอาดอากาศ

สําหรับแต่ละ **รูปแบบการทํางานทางกายภาพที่สนับสนุน**, เลือกวิธีการควบคุมอย่างอิสระ:

| วิธีการ | ความหมาย |
| --- | --- |
| **มีอยู่** | ปิดการทํางานกับเส้นทางของเครื่องควบคุมที่มีอยู่ |
| **อัตโนมัติ** | ตามมา HEMความต้องการที่วัด หลักฐานและอนุญาตที่เนื่องจากสถานการณ์ |
| **PID** | ใช้การควบคุมสัดส่วน, องค์ประกอบและอนุพันธ์ที่เนื่องจากการตอบสนอง เมื่ออุปกรณ์และการวัดรองรับมัน |
| **คู่มือ** | การควบคุมผ่านการขอและเป้าหมายที่ได้รับการสนับสนุนอย่างชัดเจน |
| **ออกไป** | ปิดเครื่องควบคุมนั่น โดยต้องมีความคุ้มครองทางกายภาพ และความต้องการในการตอบสนอง |

ตัวอย่างเช่น เครื่องปรับอากาศหนึ่งอาจใช้ **PID สําหรับการทําความร้อน** และ **อัตโนมัติในการเย็น**เครื่องลดความชื้นสามารถมีตัวของมันเอง PID การปรับระดับเป้าหมายและเวลารอบ แฟนที่มีสิทธิ์สามารถใช้ PID เมื่อมีผลตอบกลับที่เหมาะสมและการควบคุมที่เฉพาะจุดหมาย

PID คือ **ไม่** การยกเลิกทั่วไป: HEM แนะนําวิธีการที่อุปกรณ์เฉพาะอย่างหนึ่ง, รูปแบบการทํางานและแหล่งข้อมูลสามารถสนับสนุนได้เท่านั้น. ตัวเลือกที่ทันสมัยรวมถึงการปรับปรุงและการปรับปรุงแบบต่อ รูปแบบ, การปรับปรุงที่เสนอ/ปรับปรุง, การทํางานเงียบสงบ และการปรับปรุงแฟนที่สนับสนุน. คุณอนุมัติการปรับปรุงที่เสนอ นอกจากคุณเลือกอย่างชัดเจนในการปรับปรุงอัตโนมัติที่จํากัด

<a id="comfortable-when-youre-home-economical-when-youre-away"></a>
### สบายสบายตอนที่อยู่บ้าน และประหยัดตอนที่ไป

HEM สามารถเลือก **ความ สบาย, บ้าน, ย้าย, นอนและสิ่งแวดล้อม** เป้าหมายจากสถานการณ์ของครัวเรือน หลักฐานห้อง และการเลือกของคุณอย่างชัดเจน

- **บ้านและนอก:** ใช้วัตถุความร้อน, การเย็นและความชื้นที่แตกต่างกันขึ้นอยู่กับการปรากฏตัวที่บ้านที่ได้รับการตรวจสอบ
- **มีห้องพัก:** ใช้อุปกรณ์ที่มีสิทธิใช้ได้เสมอ เมื่อมีความต้องการ, เพียงแค่ขณะที่ห้องของมันมีคนอยู่, หรือเพียงแค่ขณะที่ห้องว่าง.
- **นอน:** ใช้เป้าหมายกลางคืน และพฤติกรรมของแฟนที่เงียบสงบขึ้น
- **สาธารณสุข** ใช้เป้าหมายที่ประหยัดเมื่อมีการตั้งค่า ประตูภายในปิด สามารถเข้าร่วมนโยบายสิ่งแวดล้อมที่คุ้มครองได้ เมื่อห้องถูกตรวจสอบว่าว่างและมีเงื่อนไขอื่น ๆ หลังประตูปิดคนเดียวไม่พิสูจน์ว่าห้องถูกแยกแยก
- **การเตรียมการตื่น:** ใช้แหล่งแจ้งเตือนถัดไปที่ตั้งไว้เพื่อปล่อย Sleep อัตโนมัติก่อนการแจ้งเตือน และให้เวลาของอุปกรณ์ที่ได้รับสิทธิในการตอบสนอง

ถ้าการใช้งาน, การมีของอุปกรณ์หรือหลักฐานอื่น ๆ ที่ต้องการไม่แน่นอน HEM ไม่เพียงแค่คิดว่ามันปลอดภัยที่จะเปิดเครื่องอัตโนมัติ

<a id="prepare-your-environment-before-you-arrive"></a>
### เตรียมสิ่งแวดล้อมของคุณ ก่อนที่คุณจะถึง

**เตรียมตัวมาถึง** เป็นการดําเนินการตามเวลาสําหรับการยืนยัน บ้าน Away. เริ่มมันจากหัวหน้าบัตรหรือ HEMเป็นเครื่องบ้าน

HEM ใช้เวลาชั่วคราว **เป้าหมายในบ้าน** ให้บริการอัตโนมัติ/PID ระบบควบคุม เพื่อให้ห้องพักสามารถเริ่มทําความอุ่นเย็น หรือปรับความชื้น ก่อนที่คุณจะกลับมา **เพียงเมื่อมันมีอนุญาตควบคุมทางกายภาพที่จําเป็น**.

การเตรียมตัวไม่ใช่คําสั่งที่จะเปิดทุกอย่าง หน่วยงานยังต้องมีความต้องการจริง, เซ็นเซอร์และอนุญาตที่มีสิทธิภาพ และต้องเคารพหน้าต่าง, เวลาเปิด/ปิดขั้นต่ํา และการป้องกันของตนเอง การกระทําสิ้นสุดเมื่อใครบางคนมาถึง, คุณยกเลิกมัน, หรือเวลาที่ตั้งค่าหมดอายุ Home Assistant การเริ่มต้นใหม่ไม่ได้เริ่มเวลาเต็ม

<a id="ventilation-advice-windows-doors-and-shading"></a>
### คําแนะนําการลมหายาก ช่องต่าง ประตู และการเงา

HEM เทียบ **สิ่งที่ห้องต้องการ** กับ **ถ้าอากาศภายนอกช่วยได้หรือไม่**.

- แนะนําการเปิดหรือปิดหน้าต่างโดยใช้วัดภายในของปัจจุบัน ความชื้นภายนอก การปรับปรุงมะเร็ง อุณหภูมิ ลม การเตือนสติอากาศ และสภาพสภาพสภาพของฝุ่นแบบเลือก
- ใช้เครื่องสัมผัสหน้าต่างและประตูที่คัดเลือก เพื่ออธิบายสภาพห้อง และหลีกเลี่ยงการรักษาการสัมผัสที่ไม่ทราบว่าปิด
- ขอให้คุณลองเปิดหน้าต่างก่อนเปิดเครื่องอัตโนมัติที่สนับสนุน แล้วต่อการควบคุมปกติหลังจากการตอบรับที่ตั้งค่ารอຖ້າจําเป็น
- ใช้ข้อมูลประตู เพื่อสื่อสารถึงขอบห้อง ระวังการลมหายาก และการปฏิบัติตามระบบ Eco ที่ได้รับการคุ้มครองเป็นทางเลือก
- บริหารกระจก, ตาบอดและเงาที่เลือกโดยใช้หน้าต่างที่เหมาะสม, อุณหภูมิ, สภาพอากาศ, ความสูงของดวงอาทิตย์และหลักฐานการส่องแสงเป็นทางเลือก

HEM สามารถให้คําปรึกษาในการลมหายใจได้โดยไม่มีหน้าต่างที่สามารถควบคุมได้ มันไม่ได้เปิดหน้าต่างด้วยตัวเอง เพียงเพราะการลมหายใจจะช่วย

<a id="humidity-mold-indication-and-air-quality"></a>
### ความชื้น ราศีอ่อนและคุณภาพอากาศ

HEM รวมการอ่านที่สนับสนุน เช่น **อุณหภูมิ, ความชื้น, CO2, สารอนุภาค, VOC, AQI และแสง** เพื่อช่วยให้คุณเข้าใจห้องละห้อง ขนาดที่สามารถใช้ได้ขึ้นอยู่กับ Home Assistant การจัดตั้ง

ของมัน **รายการอัฟฟอลด์** การประเมินภาวะความชื้นที่พื้นผิวเย็นจากอุณหภูมิในห้องและภายนอก และการวัดการคัดกรอง เมื่อตั้งค่าถูกต้อง มันสามารถส่งผลต่อเป้าหมายของเครื่องควบคุมความชื้นอัตโนมัติที่สนับสนุน

**การชี้แจงของอวัยวะเป็นประมาณการ ไม่ใช่เครื่องตรวจจับอวัยวะหรือสปอร์** ข้อมูลเซนเซอร์ที่หายไปหรือเก่าไม่ได้เป็นเหตุผลในการสั่งหน่วยอุปกรณ์ใหม่

<a id="announcements-diagnostics-and-protection"></a>
### ประกาศ การตรวจสอบ และการป้องกัน

คุณสามารถส่งคําแนะนําและเตือนที่เกี่ยวข้องผ่านระบบที่ตั้ง Home Assistant ข่าวสาร, TTS / เครื่องเล่นสื่อ หรือ **แจ้งแจง**, ด้วยคํานวณ AI เป็นทางเลือก AI สามารถเปลี่ยนวิธีการประโยคของข้อความ HEMการตัดสินใจควบคุมร่างกายยังคงเป็นเรื่องกําหนด

HEM รวมถึงการป้องกันและการตรวจสอบเฉพาะอุปกรณ์

- ระยะเวลาการเปิดและปิดขั้นต่ํา, การตั้งค่าเวลาทํางานสูงสุด และการควบคุมสวิตช์ไฟฟ้าภายนอกที่สนับสนุน
- ขั้นขัดขวางหน้าต่างและห้องพัก การควบคุมการออเวอร์ไรดแบบมือและการตรวจสอบการรับรองคําสั่งในพื้นที่
- การรายงานความผิดพลาดและอุปกรณ์ที่ไม่ได้มี พร้อมกับการเลือกพฤติกรรมการแจ้งความสําหรับอุปกรณ์แต่ละตัว
- ป้องกันหลังปิดการทํางานเป็นทางเลือกสําหรับการตั้งความร้อนต่อเนื่องตามคําสั่งปิดการทํางาน โดยมีการติดตามที่ระวังและการพยายามฟื้นฟูที่จํากัด
- เหตุผลการรอที่ชัดเจน สถานการณ์การทํางานปัจจุบัน และการมีแหล่ง เพื่อให้คุณสามารถสืบสวน ก่อนที่จะเปิดให้มีการควบคุมมากขึ้น

**ขอบเขตความปลอดภัยยังคงมีผลแม้กระทั่งเมื่อสัญญาณเตือนปิด** HEM ไม่เคยพิจารณาการส่งคําสั่งที่ประสบความสําเร็จเป็นหลักฐานว่าอุปกรณ์ตอบสนองทางกายภาพ

<a id="getting-started"></a>
## เริ่มต้น

1. **จัดห้องของคุณ** ใน Home Assistantสร้างหรือตรวจสอบพื้นที่ของคุณ และมอบเซ็นเซอร์และอุปกรณ์ที่เหมาะสมกับแต่ละ
2. **เลือกอะไรให้ติดตาม** เพิ่ม HEM, เลือกห้องที่คุณสนใจและรีวิวอุณหภูมิ, ความชื้น, หน้าต่าง, คุณภาพของอากาศและแหล่งอุปกรณ์ที่แนะนํา คุณสามารถทิ้งกลุ่มที่ไม่ได้ใช้เปล่า
3. **ปรับข้อมูลที่แบ่งปัน** เลือกแหล่งอากาศกลางแจ้ง / คุณภาพอากาศที่มี, หลักฐานการใช้งานของครัวเรือนและจุดหมายการประกาศที่คุณต้องการ
4. **เพิ่มบัตร** เปิดตู้ดช็อตในโหมดแก้ไข และเพิ่ม **Home ผู้จัดการสิ่งแวดล้อม** เริ่มด้วยการติดตามห้อง, การอ่านและคําปรึกษาด้านลมหายใจ
5. **เปิดการควบคุมได้เพียงเมื่อมีประโยชน์** เปิดห้อง, เลือกอุปกรณ์ที่สนับสนุน, ตรวจสอบการควบคุมของมันและอย่างชัดเจนเลือกอัตโนมัติหรือ PID สําหรับโหมดที่คุณต้องการ HEM เพื่อปฏิบัติการ

คุณรู้ **ไม่** เริ่มจากเซนเซอร์ที่คุณมี และนํามาควบคุมอัตโนมัติหนึ่งอุปกรณ์ต่อครั้ง

<a id="add-the-card-manually"></a>
### เพิ่มบัตรด้วยมือ

การบูรณาการปกติจะจดทะเบียนบัตร Lovelace ของตัวเอง หากคุณชอบ YAML ใช้:

~~~yaml
type: custom:home-environment-manager-card
~~~

หากคุณ Home Assistant การติดตั้งมีมากกว่า 1 HEM แนะนําเซนเซอร์ คุณอาจต้องตั้งค่าที่เหมาะสม **หน่วยงาน** โดยชัดเจน:

~~~yaml
type: custom:home-environment-manager-card
entity: sensor.your_hem_recommendation_sensor
~~~

สําหรับคําแนะนําขั้นตอนต่อขั้นตอนเกี่ยวกับแหล่งห้อง PID การตั้งค่า, ประโยคหน้าต่าง, การเตรียมการ, การปรับปรุง mold, การเงาแสงอาทิตย์และการจัดส่งประกาศ [คู่มือการจัดตั้งรายละเอียด](../../docs/advanced-configuration.md).

<a id="installation"></a>
## การติดตั้ง

<a id="hacs--home-assistant-community-store"></a>
### HACS / Home Assistant ร้านชุมชน

1. เปิด **HACS** ใน Home Assistant.
2. เพิ่ม **https://github.com/Chreece/HA-Home-Environment-Manager** เป็น **คลังเก็บสินค้าตามสั่ง** ใน **การรวม** ประเภทถ้ามันไม่ได้อยู่ในรายการแล้ว
3. ค้นหา **Home ผู้จัดการสิ่งแวดล้อม** และติดตั้งมัน
4. เริ่มใหม่ **Home Assistant** เพื่อบรรจุการรวม
5. ไปที่ **การตั้งค่า → อุปกรณ์ & บริการ → เพิ่มการรวม**ค้นหา **Home ผู้จัดการสิ่งแวดล้อม** และเสร็จการจัดตั้ง

<a id="manual-installation"></a>
### การติดตั้งด้วยมือ

สําเนาสํานักเก็บของ **custom_components/environment_manager** โฟลเดอร์เข้าที่ตรงกัน **custom_components** รายการในของคุณ Home Assistant การตั้งค่า, การรักษาชื่อเอกสาร **environment_manager**เริ่มใหม่ Home Assistant และเพิ่มการรวม **การตั้งค่า → อุปกรณ์ & บริการ**.

สําหรับการปรับเปลี่ยนการติดตั้งต่อมา ให้เก็บข้อมูลที่มีอยู่ HEM การเข้าและการตั้งค่าของการสื่อรวม โหลดด Dashboard ในบrowser ของคุณถ้าการปรากฏของบัตรไม่ได้อัพเดททันที

<a id="common-questions"></a>
## คําถามทั่วไป

**ฉันใช้ได้มั้ย HEM โดยไม่ให้มันควบคุมอุปกรณ์ของฉัน?**

ใช่ การติดตาม การวัด การปรึกษาด้านลมหายใจ ประวัติศาสตร์ และอาการสิ่งแวดล้อมหลายอย่าง ทํางานได้โดยไม่ให้เครื่องใช้

**วิลล์ HEM ปฏิบัติการควบคุมอุปกรณ์ทุกเครื่องที่มันค้นพบ?**

ไม่ คุณเลือกอุปกรณ์ฟิสิกส์ที่คุณต้องการจัดการ และเลือกวิธีการควบคุมโดยชัดเจนสําหรับโหมดที่สนับสนุน คุณสมบัติของเซนเซอร์และความสามารถของอุปกรณ์พื้นเมืองยังคงกําหนดสิ่งที่เป็นไปได้

**เครื่องมือทุกเครื่องจะรองรับ PID?**

- ไม่ ไม่ HEM การสนับสนุน PID สําหรับ **คุ้มค่า** เส้นทางการทําความร้อน, การเย็น, ความชื้น หรือการควบคุมแฟน เมื่ออุปกรณ์และการวัดที่เลือกให้ความสามารถและความคิดเห็นที่จําเป็น PID การควบคุม

**ฉันสามารถให้กฎที่แตกต่างกันทุกห้องได้หรือไม่**

ใช่. สภาพการใช้งาน, การพฤติกรรมในการนอน, แหล่ง, เป้าหมาย และความชอบด้านความปลอดภัยบางส่วนอาจแตกต่างกันตามห้อง, ขณะที่อุปกรณ์ฟิสิกส์แต่ละตัว มีการทํางานและการป้องกันของตัวเอง

**สามารถ HEM เตรียมบ้านฉันให้พร้อมในขณะที่ฉันไป?**

ใช่แล้ว **เตรียมตัวมาถึง** ให้ผู้ควบคุมอัตโนมัติที่ได้รับอนุญาตใช้งานได้ในระยะเวลาที่จํากัด สําหรับการควบคุมอัตโนมัติที่ได้รับอนุญาตแล้ว

**การแนะนําของ  ⁇ ดีสําหรับอากาศ  ⁇  เปิดหน้าต่างของฉันหรือไม่?**

ไม่ มันอธิบายว่าเมื่อการลื่นอากาศอาจช่วยได้ การเคลื่อนไหวอัตโนมัติ เป็นคุณสมบัติที่แตกต่างกัน, opt-in สําหรับเงาหรือปกรองที่ได้รับการสนับสนุนที่ได้รับการรับรอง, ภายใต้การตรวจสอบความปลอดภัยของพวกเขาเอง.

**แล้วถ้าเซนเซอร์หรืออุปกรณ์ไม่ได้ใช้ได้ล่ะ**

HEM การแยกข้อมูลที่ไม่ทราบจากการอ่านจริง การเก็บข้อมูลของผู้ควบคุมที่ตั้งไว้เมื่อเป็นไปได้ และเปิดเผยเหตุผลการรอและการตรวจสอบ การควบคุมอัตโนมัติยังต้องมีอํานาจและหลักฐานที่ใช้อยู่

## การช่วยเหลือและแก้ไขปัญหา

ถ้ามีอะไรผิดปกติ ดูห้องที่เกี่ยวข้อง หรือห้องควบคุม **เหตุผล**, **การตรวจสอบ**, ความมีของแหล่งและวิธีการควบคุมปัจจุบัน [คู่มือการจัดตั้งรายละเอียด](../../docs/advanced-configuration.md) ครอบคลุมภาวะรอคอยทั่วไป PID การได้รับสิทธิ์, ติดต่อ Windows และแก้ไขปัญหาในการตอบสนองของอุปกรณ์

สําหรับปัญหาที่สามารถนํามาสร้างได้ [เปิด a GitHub เรื่อง](https://github.com/Chreece/HA-Home-Environment-Manager/issues) กับการพฤติกรรมที่คาดหวัง การพฤติกรรมจริง การตั้งค่าห้อง / อุปกรณ์ที่เกี่ยวข้อง และขั้นตอนในการสร้างขึ้น

การส่งส่วนร่วมและการปรับปรุง [ส่งผล](../../CONTRIBUTING.md).
