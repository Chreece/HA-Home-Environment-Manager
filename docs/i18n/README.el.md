# HEM - Home Environment Manager

<p align="center">
  <img src="../../.github/assets/hem-logo.svg" alt="Λογότυπο του HEM" width="420">
</p>

<p align="center"><strong>Το περιβάλλον ολόκληρου του σπιτιού σας, σε μία κάρτα του Home Assistant.</strong></p>

**Το HEM βοηθά το σπίτι σας να κατανοεί τις συνθήκες που επικρατούν και να ανταποκρίνεται στις ανάγκες κάθε χώρου.** Συγκεντρώνει αισθητήρες του Home Assistant, μετεωρολογικά δεδομένα, πληροφορίες παρουσίας και συμβατές συσκευές θέρμανσης, ψύξης και διαχείρισης αέρα. Έτσι, μπορείτε να παρακολουθείτε την ποιότητα του αέρα, να λαμβάνετε χρήσιμες προτάσεις αερισμού, να βελτιώνετε την άνεση και, εφόσον το επιλέξετε, να αυτοματοποιείτε τη λειτουργία των συσκευών σας.

Για παράδειγμα, το HEM μπορεί να μειώνει τη θέρμανση όταν λείπουν όλοι, να προετοιμάζει επιλεγμένα δωμάτια πριν επιστρέψετε, να χρησιμοποιεί διαφορετικό στόχο υγρασίας κατά τον ύπνο ή να σας προτείνει να ανοίξετε ένα παράθυρο προτού ενεργοποιήσει έναν αφυγραντήρα. Μπορεί επίσης να λειτουργεί **μόνο για παρακολούθηση και προτάσεις**, χωρίς να ελέγχει καμία συσκευή.

**Εσείς έχετε τον έλεγχο.** Κάθε δωμάτιο διαθέτει ξεχωριστές ρυθμίσεις. Κάθε συμβατή συσκευή έχει τις δικές της μεθόδους ελέγχου, λειτουργίες, στόχους και περιορισμούς ασφαλείας. Η επιλογή μιας συσκευής δεν αποτελεί από μόνη της άδεια για να τη χειρίζεται το HEM.

<a id="what-can-hem-do"></a>
## Τι μπορεί να κάνει το HEM;

| Περίσταση | Πώς μπορεί να βοηθήσει το HEM |
| --- | --- |
| **Το σπίτι είναι άδειο** | Εφαρμόζει τους στόχους απουσίας (Away), λαμβάνει υπόψη τους κανόνες παρουσίας κάθε δωματίου και αποφεύγει την άσκοπη λειτουργία επιλεγμένων συσκευών. |
| **Επιστρέφετε στο σπίτι** | Με την ενέργεια **Προετοιμασία άφιξης** χρησιμοποιεί προσωρινά τους στόχους άνεσης Home σε κατάλληλους αυτόματους ελεγκτές, παρότι δεν έχει επιστρέψει ακόμη κανείς. |
| **Κάποιος κοιμάται** | Εφαρμόζει στόχους ύπνου (Sleep), περιορίζει τον θόρυβο των ανεμιστήρων ή κρατά επιλεγμένες συσκευές απενεργοποιημένες όταν όλοι οι κατειλημμένοι χώροι βρίσκονται σε κατάσταση ύπνου. |
| **Ένα δωμάτιο έχει πολλή υγρασία** | Συγκρίνει τη σχετική υγρασία και την εκτίμηση κινδύνου μούχλας με τους στόχους, προτείνει αερισμό ή ελέγχει έναν αφυγραντήρα για τον οποίο έχετε δώσει άδεια, με αυτόματη ρύθμιση ή PID. |
| **Έχει ζέστη και έντονη ηλιοφάνεια** | Εξετάζει θερμοκρασία, ηλιακή ακτινοβολία, καιρό και αισθητήρες παραθύρων προτού κινήσει σκίαστρα που έχετε επιτρέψει να ελέγχει. |
| **Ο εξωτερικός αέρας είναι καταλληλότερος** | Προτείνει αερισμό με βάση τις ανάγκες του χώρου, την εξωτερική ρύπανση, τη θερμοκρασία, την υγρασία, τον άνεμο και, όπου διατίθενται, δεδομένα γύρης ή προειδοποιήσεις καιρού. |
| **Ένα θερμαντικό σώμα ή μια θερμοστατική βαλβίδα (TRV) δεν ανταποκρίνεται** | Εμφανίζει ότι η συσκευή δεν είναι διαθέσιμη ή βρίσκεται σε αναμονή, διατηρεί τις ρυθμίσεις της και αναφέρει σχετικά σφάλματα, χωρίς να θεωρεί αυθαίρετα ότι αποκαταστάθηκε η τροφοδοσία ή η επικοινωνία της. |

Πρόκειται για παραδείγματα και όχι για ενέργειες που επιβάλλει το HEM σε κάθε εγκατάσταση. Το τι μπορεί να κάνει εξαρτάται από τους αισθητήρες που έχετε επιλέξει, τις πραγματικές δυνατότητες των συσκευών σας στο Home Assistant και τις ρυθμίσεις που έχετε ενεργοποιήσει.

<a id="explore-the-features"></a>
## Ανακαλύψτε τις δυνατότητες

<a id="a-complete-home-dashboard"></a>
### Συνολική εικόνα του σπιτιού

Η κάρτα HEM συγκεντρώνει σημαντικές πληροφορίες χωρίς να χρειάζεται να ανοίγετε διαφορετικές ενσωματώσεις.

- Δείτε τις εξωτερικές συνθήκες, την ποιότητα του αέρα και αν ενδείκνυται να αερίσετε το σπίτι.
- Συγκρίνετε όλους τους χώρους που παρακολουθείτε: θερμοκρασία, σχετική υγρασία, AQI, PM2.5, ένδειξη κινδύνου μούχλας, φωτισμό και άλλες διαθέσιμες μετρήσεις.
- Αναπτύξτε έναν χώρο για αναλυτικές μετρήσεις, πληροφορίες για παράθυρα και πόρτες, κατάσταση συσκευών, ενεργούς ελεγκτές, αιτίες αναμονής και εκτιμήσεις σχετικές με τη θερμική συμπεριφορά του κτιρίου.
- Εξετάστε ιστορικό και τάσεις, δείτε ποιοι αισθητήρες συμμετέχουν σε έναν μέσο όρο και ξεχωρίστε τις μετρήσεις που λείπουν από τις πραγματικές τιμές.
- Ομαδοποιήστε τα δωμάτια ανά όροφο σύμφωνα με το Home Assistant ή εμφανίστε μια απλή λίστα, αν δεν έχετε ορίσει ορόφους.

<a id="different-settings-for-the-home-each-room-and-each-device"></a>
### Ξεχωριστές ρυθμίσεις για σπίτι, δωμάτια και συσκευές

Το HEM διαχωρίζει τους γενικούς κανόνες του σπιτιού από τις ανάγκες κάθε χώρου και τις ρυθμίσεις κάθε συσκευής.

| Επίπεδο ρυθμίσεων | Τι μπορείτε να ρυθμίσετε |
| --- | --- |
| **Σπίτι** | Πηγές εξωτερικού καιρού και ρύπανσης, δωμάτια υπό παρακολούθηση, γενικά όρια αερισμού, παρουσία στο σπίτι, προετοιμασία άφιξης και τρόπους αποστολής ανακοινώσεων. |
| **Δωμάτιο** | Αισθητήρες θερμοκρασίας και υγρασίας, όρια ποιότητας αέρα, αισθητήρες παραθύρων και θυρών, κανόνες ύπνου και παρουσίας, στόχους άνεσης, αερισμό και σκίαση. |
| **Συσκευή** | Διαθέσιμες λειτουργίες, μέθοδο ελέγχου Automatic/Manual/PID, στόχους ανά προφίλ, αισθητήρες, αθόρυβη λειτουργία ανεμιστήρα, ελάχιστους χρόνους λειτουργίας, προστασίες τροφοδοσίας, συμπεριφορά σε ανοιχτά παράθυρα και ειδοποιήσεις σφαλμάτων. |

Οι ρυθμίσεις σπιτιού, δωματίου και συσκευής είναι οργανωμένες σε ομάδες με δυνατότητα αναζήτησης στην κάρτα. Επιλέξτε **Βασικές**, **Προηγμένες** ή **Εξειδικευμένες** για να ορίσετε ποιες ρυθμίσεις εμφανίζονται. Οι Βασικές περιλαμβάνουν τις καθημερινές επιλογές και την απαραίτητη αρχική διαμόρφωση. Οι Προηγμένες προσθέτουν χειροκίνητη ρύθμιση των συντελεστών PID και λεπτομερείς προσαρμογές. Οι Εξειδικευμένες προσθέτουν ειδικά μοντέλα και ρυθμίσεις δυναμικότητας. Κάθε επίπεδο περιλαμβάνει και τα προηγούμενα. Όποτε αλλάζει η εγκατάσταση του Home Assistant, μπορείτε να ανανεώνετε τις διαθέσιμες πηγές. <!-- HEM-I18N:levels -->


<a id="climate-control-and-pid-device-by-device"></a>
### Έλεγχος κλίματος και PID, ξεχωριστά για κάθε συσκευή

Το HEM μπορεί να συνεργάζεται με συμβατές συσκευές Home Assistant τύπου **climate**, **humidifier** και **fan**: συστήματα θέρμανσης, ψύξης, αφύγρανσης, ύγρανσης και υποστηριζόμενες συσκευές κυκλοφορίας ή καθαρισμού αέρα.

Για **κάθε υποστηριζόμενη φυσική λειτουργία** επιλέγετε ανεξάρτητα τη μέθοδο ελέγχου:

| Μέθοδος | Τι σημαίνει |
| --- | --- |
| **Existing** | Η λειτουργία παραμένει στον ήδη υπάρχοντα τρόπο ελέγχου της συσκευής. |
| **Automatic** | Το HEM λαμβάνει υπόψη τις μετρήσεις, τις ανάγκες του χώρου, τους στόχους ανά περίσταση και τις άδειες που έχετε δώσει. |
| **PID** | Χρησιμοποιεί ανατροφοδότηση από τις μετρήσεις και αναλογικό, ολοκληρωτικό και διαφορικό έλεγχο, όπου το επιτρέπουν η συσκευή και οι αισθητήρες. |
| **Manual** | Χειρίζεστε τη συσκευή μέσω των διαθέσιμων χειροκίνητων εντολών και στόχων. |
| **Off** | Ο συγκεκριμένος ελεγκτής παραμένει απενεργοποιημένος, με σεβασμό στους απαιτούμενους ελέγχους προστασίας και ανατροφοδότησης. |

Για παράδειγμα, ένα κλιματιστικό μπορεί να χρησιμοποιεί **PID στη θέρμανση** και **Automatic στην ψύξη**. Ένας αφυγραντήρας μπορεί να έχει ξεχωριστή ρύθμιση PID, στόχους και χρονισμούς κύκλου λειτουργίας. Αντίστοιχα, ένας κατάλληλος ανεμιστήρας μπορεί να ελέγχεται μέσω PID όταν υπάρχει αξιόπιστη ανατροφοδότηση για τη λειτουργία του.

Το PID **δεν λειτουργεί ως γενική παράκαμψη των κανόνων**. Το HEM προτείνει μόνο μεθόδους που υποστηρίζονται πραγματικά από τη συσκευή, τη συγκεκριμένη λειτουργία και τις διαθέσιμες μετρήσεις. Στις προχωρημένες ρυθμίσεις περιλαμβάνονται βαθμονόμηση και παράμετροι ανά λειτουργία, προτάσεις προσαρμογής, αθόρυβη λειτουργία και υποστηριζόμενες βαθμίδες ανεμιστήρα. Οι προτεινόμενες αλλαγές χρειάζονται την έγκρισή σας, εκτός αν ενεργοποιήσετε ρητά την προσαρμογή εντός καθορισμένων ορίων.

<a id="comfortable-when-youre-home-economical-when-youre-away"></a>
### Άνεση όταν είστε σπίτι, εξοικονόμηση όταν λείπετε

Το HEM μπορεί να επιλέγει στόχους **Comfort, Home, Away, Sleep και Eco** με βάση την κατάσταση του σπιτιού, τις πληροφορίες από κάθε χώρο και τις προσωπικές σας επιλογές.

- **Home και Away:** Διαφορετικοί στόχοι θέρμανσης, ψύξης και υγρασίας ανάλογα με το αν έχει επιβεβαιωθεί ότι βρίσκεται κάποιος στο σπίτι.
- **Παρουσία στο δωμάτιο:** Μια συμβατή συσκευή μπορεί να λειτουργεί όταν υπάρχει ανάγκη, μόνο όταν το δωμάτιο είναι κατειλημμένο ή μόνο όταν είναι άδειο.
- **Sleep:** Στόχοι ύπνου και πιο αθόρυβη λειτουργία ανεμιστήρων. Μπορείτε να ορίσετε μια συσκευή να παραμένει κλειστή όταν όλοι οι κατειλημμένοι χώροι βρίσκονται σε κατάσταση ύπνου.
- **Eco:** Οικονομικότεροι στόχοι όπου τους έχετε ρυθμίσει. Μια κλειστή εσωτερική πόρτα μπορεί να συμβάλλει σε έναν προσεκτικά ελεγχόμενο κανόνα Eco, εφόσον έχει επιβεβαιωθεί ότι ο χώρος είναι άδειος και πληρούνται πρόσθετες προϋποθέσεις. Η κλειστή πόρτα από μόνη της δεν αποδεικνύει ότι ο χώρος είναι απομονωμένος.
- **Προετοιμασία αφύπνισης:** Με βάση την επόμενη προγραμματισμένη αφύπνιση, το HEM μπορεί να τερματίζει έγκαιρα την αυτόματη κατάσταση Sleep, ώστε οι κατάλληλες συσκευές να έχουν χρόνο να ανταποκριθούν.

Αν η παρουσία, η διαθεσιμότητα μιας συσκευής ή κάποια άλλη απαραίτητη πληροφορία είναι αβέβαιη, το HEM δεν θεωρεί αυθαίρετα ότι είναι ασφαλές να ξεκινήσει ο αυτόματος έλεγχος.

<a id="prepare-your-environment-before-you-arrive"></a>
### Προετοιμασία του σπιτιού πριν επιστρέψετε

Η **Προετοιμασία άφιξης** είναι μια χρονικά περιορισμένη ενέργεια που διατίθεται όταν έχει επιβεβαιωθεί ότι το σπίτι βρίσκεται σε κατάσταση Away. Μπορείτε να την ξεκινήσετε από την κεφαλίδα της κάρτας ή από τη συσκευή Home του HEM.

Το HEM εφαρμόζει προσωρινά τους καθορισμένους **στόχους Home** στους κατάλληλους ελεγκτές Automatic/PID. Έτσι, επιλεγμένα δωμάτια μπορούν να αρχίσουν να ζεσταίνονται, να δροσίζονται ή να ρυθμίζουν την υγρασία τους πριν επιστρέψετε. Η ενέργεια μπορεί επίσης να επιτρέψει προσωρινά τη λειτουργία ενός ελεγκτή που κανονικά απαιτεί παρουσία στο δωμάτιο, **μόνο εφόσον έχει ήδη δοθεί η απαραίτητη άδεια χειρισμού της φυσικής συσκευής**.

Αυτό δεν σημαίνει ότι ενεργοποιούνται όλες οι συσκευές. Πρέπει να υπάρχει πραγματική ανάγκη λειτουργίας, έγκυρες μετρήσεις και η απαιτούμενη εξουσιοδότηση. Εξακολουθούν να ισχύουν οι περιορισμοί παραθύρων, οι ελάχιστοι χρόνοι ON/OFF και όλες οι προστασίες της συσκευής. Η προετοιμασία ολοκληρώνεται όταν επιστρέψει κάποιος, την ακυρώσετε ή λήξει ο καθορισμένος χρόνος. Μια επανεκκίνηση του Home Assistant δεν ξεκινά το χρονόμετρο από την αρχή.

<a id="ventilation-advice-windows-doors-and-shading"></a>
### Προτάσεις αερισμού, παράθυρα, πόρτες και σκίαση

Το HEM συγκρίνει **τι χρειάζεται κάθε δωμάτιο** με **το αν ο εξωτερικός αέρας μπορεί να βοηθήσει**.

- Προτείνει άνοιγμα ή κλείσιμο παραθύρων βάσει των εσωτερικών μετρήσεων, της εξωτερικής υγρασίας, της ρύπανσης, της θερμοκρασίας, του ανέμου, των προειδοποιήσεων καιρού και, προαιρετικά, των δεδομένων γύρης.
- Ο δείκτης AQI είναι προαιρετικός. Αν δεν έχει οριστεί η κλίμακα του παρόχου, εμφανίζεται ένδειξη ελλιπών δεδομένων· αυτό από μόνο του δεν εμποδίζει τον αερισμό ούτε αποτελεί λόγο να κλείσει ένα παράθυρο. Οι έγκυρες μετρήσεις ρύπων και οι πραγματικά επικίνδυνες τιμές AQI με σωστά ορισμένη κλίμακα εξακολουθούν να λαμβάνονται υπόψη. <!-- HEM-I18N:aqi -->
- Χρησιμοποιεί τους επιλεγμένους αισθητήρες παραθύρων και θυρών για να ερμηνεύει καλύτερα τις συνθήκες ενός χώρου, χωρίς να θεωρεί «κλειστό» έναν αισθητήρα άγνωστης κατάστασης.
- Μπορείτε προαιρετικά να προσθέσετε μπαλκονόπορτες ή πόρτες βεράντας με κλάση δυαδικού αισθητήρα `door` ή `opening` στο Home Assistant ως **εισόδους παραθύρων**. Εμφανίζονται στον επιλογέα παραθύρων του δωματίου, αλλά **δεν επιλέγονται ποτέ αυτόματα**. Η κανονική παρακολούθηση θυρών παραμένει ανεξάρτητη. <!-- HEM-I18N:balcony -->
- Μπορεί, αν το επιλέξετε, να σας προτείνει να ανοίξετε ένα παράθυρο πριν ενεργοποιήσει μια συμβατή αυτόματη συσκευή. Αν χρειάζεται, συνεχίζει τον κανονικό έλεγχο μετά τον καθορισμένο χρόνο αναμονής.
- Αξιοποιεί την κατάσταση των εσωτερικών θυρών για την εκτίμηση της επικοινωνίας μεταξύ χώρων, για προειδοποιήσεις αερισμού και για προαιρετικούς, προσεκτικά ελεγχόμενους κανόνες Eco.
- Μπορεί να χειρίζεται ρολά, περσίδες και σκίαστρα που έχετε επιλέξει, χρησιμοποιώντας κατάλληλες πληροφορίες για παράθυρα, θερμοκρασία, καιρό, ύψος του ήλιου και, προαιρετικά, ένταση φωτισμού.

Για να δίνει προτάσεις αερισμού, το HEM δεν χρειάζεται ηλεκτρικά ελεγχόμενα παράθυρα. **Δεν ανοίγει από μόνο του ένα παράθυρο** απλώς επειδή ο αερισμός θα ήταν χρήσιμος.

<a id="humidity-mold-indication-and-air-quality"></a>
### Υγρασία, εκτίμηση κινδύνου μούχλας και ποιότητα αέρα

Το HEM συνδυάζει διαθέσιμες μετρήσεις, όπως **θερμοκρασία, υγρασία, CO₂, αιωρούμενα σωματίδια, VOC, AQI και φωτεινότητα**, για να σας δίνει πληρέστερη εικόνα κάθε δωματίου. Οι μετρήσεις που εμφανίζονται εξαρτώνται από τους αισθητήρες της εγκατάστασής σας.

Η **ένδειξη κινδύνου μούχλας** εκτιμά τις συνθήκες υγρασίας στην ψυχρότερη επιφάνεια ενός χώρου, με βάση την εσωτερική και την εξωτερική θερμοκρασία και μια μέτρηση βαθμονόμησης. Όταν είναι σωστά ρυθμισμένη, μπορεί να επηρεάζει τον αποτελεσματικό στόχο υγρασίας ενός συμβατού αυτόματου ελεγκτή.

**Πρόκειται για εκτίμηση, όχι για αισθητήρα που ανιχνεύει μούχλα ή σπόρια.** Ελλιπή ή παρωχημένα δεδομένα δεν δικαιολογούν νέες εντολές προς συσκευές βάσει αυτής της ένδειξης.

<a id="announcements-diagnostics-and-protection"></a>
### Ανακοινώσεις, διαγνωστικά και προστασίες

Μπορείτε να λαμβάνετε προτάσεις και ειδοποιήσεις μέσω του Home Assistant, συστημάτων εκφώνησης TTS, συσκευών αναπαραγωγής πολυμέσων ή του **Announcement Hub**. Προαιρετικά, η τεχνητή νοημοσύνη μπορεί να διατυπώνει πιο φυσικά ένα μήνυμα. Οι αποφάσεις για τον χειρισμό των συσκευών παραμένουν ντετερμινιστικές και δεν λαμβάνονται από την τεχνητή νοημοσύνη.

Το HEM διαθέτει επίσης προστασίες και διαγνωστικά ανά συσκευή:

- Ελάχιστους χρόνους ενεργοποίησης και απενεργοποίησης, όρια μέγιστης διάρκειας λειτουργίας και υποστηριζόμενο χειρισμό εξωτερικού διακόπτη τροφοδοσίας.
- Περιορισμούς βάσει παραθύρων και παρουσίας, σεβασμό στις χειροκίνητες παρεμβάσεις και έλεγχο επιβεβαίωσης των εντολών από την ίδια τη συσκευή.
- Ειδοποιήσεις για σφάλματα ή μη διαθέσιμες συσκευές, με ξεχωριστές επιλογές ειδοποίησης ανά συσκευή.
- Προαιρετική επιτήρηση μετά από εντολή OFF, όταν υπάρχουν ενδείξεις ότι η θέρμανση συνεχίζεται, με προσεκτικούς ελέγχους και περιορισμένες προσπάθειες αποκατάστασης.
- Σαφείς αιτίες αναμονής, τρέχουσα κατάσταση λειτουργίας και ένδειξη διαθεσιμότητας των πηγών, ώστε να μπορείτε να διερευνάτε ένα πρόβλημα πριν ενεργοποιήσετε επιπλέον αυτοματισμούς.

**Οι περιορισμοί ασφαλείας εξακολουθούν να ισχύουν ακόμη κι αν απενεργοποιήσετε μια ειδοποίηση.** Το ότι μια εντολή στάλθηκε επιτυχώς δεν σημαίνει απαραίτητα ότι η συσκευή εκτέλεσε πράγματι την ενέργεια.

<a id="getting-started"></a>
## Πρώτα βήματα

1. **Οργανώστε τα δωμάτιά σας.** Δημιουργήστε ή ελέγξτε τις Περιοχές (Areas) στο Home Assistant και αντιστοιχίστε τους κατάλληλους αισθητήρες και συσκευές σε καθεμία.
2. **Επιλέξτε τι θα παρακολουθείτε.** Προσθέστε το HEM, επιλέξτε τους χώρους που σας ενδιαφέρουν και ελέγξτε τις προτεινόμενες πηγές θερμοκρασίας, υγρασίας, παραθύρων, ποιότητας αέρα και συσκευών. Μπορείτε να αφήσετε κενές τις κατηγορίες που δεν χρησιμοποιείτε.
3. **Ρυθμίστε τα κοινά δεδομένα.** Επιλέξτε διαθέσιμες πηγές καιρού και ποιότητας εξωτερικού αέρα, στοιχεία παρουσίας στο σπίτι και, αν θέλετε, παραλήπτες ανακοινώσεων.
4. **Προσθέστε την κάρτα.** Ανοίξτε έναν πίνακα ελέγχου σε λειτουργία επεξεργασίας και προσθέστε την κάρτα **Home Environment Manager**. Ξεκινήστε παρακολουθώντας τις μετρήσεις των δωματίων και τις προτάσεις αερισμού.
5. **Ενεργοποιήστε έλεγχο μόνο όπου χρειάζεται.** Ανοίξτε ένα δωμάτιο, επιλέξτε μια συμβατή συσκευή, εξετάστε τον ελεγκτή της και ενεργοποιήστε ρητά Automatic ή PID για τις λειτουργίες που θέλετε να χειρίζεται το HEM.

**Δεν χρειάζεστε έξυπνη συσκευή σε κάθε δωμάτιο.** Ξεκινήστε με τους αισθητήρες που έχετε ήδη και ενεργοποιήστε τον αυτόματο έλεγχο σταδιακά, μία συσκευή τη φορά.

<a id="add-the-card-manually"></a>
### Χειροκίνητη προσθήκη της κάρτας

Η ενσωμάτωση συνήθως καταχωρίζει αυτόματα τη δική της κάρτα Lovelace. Αν προτιμάτε YAML:

~~~yaml
type: custom:home-environment-manager-card
~~~

Αν η εγκατάστασή σας στο Home Assistant διαθέτει περισσότερους από έναν αισθητήρες προτάσεων HEM, ίσως χρειαστεί να ορίσετε ρητά την κατάλληλη **οντότητα (entity)**:

~~~yaml
type: custom:home-environment-manager-card
entity: sensor.your_hem_recommendation_sensor
~~~

Για αναλυτικές οδηγίες σχετικά με πηγές δεδομένων, προφίλ, ρυθμίσεις PID, κανόνες παραθύρων, προετοιμασία άφιξης, βαθμονόμηση εκτίμησης μούχλας, σκίαση και ανακοινώσεις, δείτε τον [αναλυτικό οδηγό ρυθμίσεων](../../docs/advanced-configuration.md).

<a id="installation"></a>
## Εγκατάσταση

<a id="hacs--home-assistant-community-store"></a>
### Μέσω HACS (Home Assistant Community Store)

1. Ανοίξτε το **HACS** στο Home Assistant.
2. Προσθέστε τη διεύθυνση **https://github.com/Chreece/HA-Home-Environment-Manager** ως **προσαρμοσμένο αποθετήριο (custom repository)** κατηγορίας **Integration**, αν δεν εμφανίζεται ήδη.
3. Βρείτε το **Home Environment Manager** και εγκαταστήστε το.
4. Επανεκκινήστε το **Home Assistant** για να φορτωθεί η ενσωμάτωση.
5. Μεταβείτε στις **Ρυθμίσεις → Συσκευές και υπηρεσίες → Προσθήκη ενσωμάτωσης**, αναζητήστε το **Home Environment Manager** και ολοκληρώστε τη ρύθμιση.

<a id="manual-installation"></a>
### Χειροκίνητη εγκατάσταση

Αντιγράψτε τον φάκελο **custom_components/environment_manager** του αποθετηρίου μέσα στον αντίστοιχο κατάλογο **custom_components** της εγκατάστασης Home Assistant, διατηρώντας το όνομα φακέλου **environment_manager**. Επανεκκινήστε το Home Assistant και προσθέστε την ενσωμάτωση από τις **Ρυθμίσεις → Συσκευές και υπηρεσίες**.

Σε επόμενες ενημερώσεις, διατηρήστε την υπάρχουσα καταχώριση HEM και τις ρυθμίσεις της. Αν η εμφάνιση της κάρτας δεν ενημερωθεί αμέσως, ανανεώστε τη σελίδα του πίνακα ελέγχου στο πρόγραμμα περιήγησής σας.

<a id="common-questions"></a>
## Συχνές ερωτήσεις

**Μπορώ να χρησιμοποιήσω το HEM χωρίς να του επιτρέψω να χειρίζεται τις συσκευές μου;**

Ναι. Η παρακολούθηση, οι μετρήσεις, οι προτάσεις αερισμού, το ιστορικό και πολλές περιβαλλοντικές ενδείξεις λειτουργούν χωρίς να ενεργοποιήσετε τον χειρισμό συσκευών.

**Θα ελέγχει αυτόματα όλες τις συσκευές που εντοπίζει;**

Όχι. Εσείς επιλέγετε ποιες φυσικές συσκευές θα διαχειρίζεται και ποια μέθοδο ελέγχου θα χρησιμοποιεί σε κάθε υποστηριζόμενη λειτουργία. Οι δυνατότητες της ίδιας της συσκευής και η καταλληλότητα των αισθητήρων εξακολουθούν να καθορίζουν τι είναι εφικτό.

**Υποστηρίζουν όλες οι συσκευές PID;**

Όχι. Το PID διατίθεται μόνο για **κατάλληλες** λειτουργίες θέρμανσης, ψύξης, ρύθμισης υγρασίας ή ανεμιστήρα, όταν υπάρχουν οι απαραίτητες δυνατότητες και αξιόπιστες μετρήσεις ανατροφοδότησης. Το HEM δεν προσθέτει τεχνητά PID σε μη υποστηριζόμενες λειτουργίες.

**Μπορώ να έχω διαφορετικούς κανόνες σε κάθε δωμάτιο;**

Ναι. Οι κανόνες παρουσίας, οι συνθήκες ύπνου, οι πηγές, οι στόχοι και ορισμένες ρυθμίσεις ασφαλείας μπορούν να διαφέρουν ανά δωμάτιο. Κάθε συσκευή διατηρεί επίσης τις δικές της ρυθμίσεις λειτουργίας και προστασίας.

**Μπορεί το HEM να προετοιμάσει το σπίτι όσο λείπω;**

Ναι. Η **Προετοιμασία άφιξης** επιτρέπει προσωρινά σε κατάλληλους, ήδη εξουσιοδοτημένους αυτόματους ελεγκτές να χρησιμοποιήσουν τους στόχους Home για περιορισμένο χρονικό διάστημα. Δεν παρακάμπτει προστασίες ούτε εγγυάται ότι θα επιτευχθεί ο στόχος.

**Αν προτείνει αερισμό, θα ανοίξει μόνο του τα παράθυρα;**

Όχι. Η πρόταση εξηγεί πότε ο αερισμός μπορεί να βοηθήσει. Η αυτόματη κίνηση είναι ξεχωριστή, προαιρετική δυνατότητα για συμβατά σκίαστρα ή καλύμματα, με δικούς τους ελέγχους ασφαλείας.

**Τι συμβαίνει αν ένας αισθητήρας ή μια συσκευή δεν είναι διαθέσιμη;**

Το HEM ξεχωρίζει τις άγνωστες καταστάσεις από τις πραγματικές μετρήσεις, διατηρεί όπου είναι δυνατόν τις ρυθμίσεις των ελεγκτών και εμφανίζει αιτίες αναμονής και διαγνωστικά. Για αυτόματο χειρισμό εξακολουθούν να απαιτούνται έγκυρες, πρόσφατες πληροφορίες και η κατάλληλη άδεια.

<a id="help-and-troubleshooting"></a>
## Βοήθεια και αντιμετώπιση προβλημάτων

Αν παρατηρήσετε κάτι ασυνήθιστο, ελέγξτε τον **Λόγο (Reason)**, τα **Διαγνωστικά (Diagnostics)**, τη διαθεσιμότητα των πηγών και την τρέχουσα μέθοδο ελέγχου του σχετικού δωματίου ή της συσκευής. Ο [αναλυτικός οδηγός ρυθμίσεων](../../docs/advanced-configuration.md) καλύπτει συνηθισμένους λόγους αναμονής, κανόνες παρουσίας, υποστήριξη PID, παράθυρα και προβλήματα απόκρισης συσκευών.

Αν ένα πρόβλημα μπορεί να αναπαραχθεί, [δημιουργήστε ένα issue στο GitHub](https://github.com/Chreece/HA-Home-Environment-Manager/issues). Περιγράψτε την αναμενόμενη και την πραγματική συμπεριφορά, τις σχετικές ρυθμίσεις δωματίου ή συσκευής και τα βήματα αναπαραγωγής. Αφαιρέστε προσωπικά δεδομένα από αρχεία καταγραφής και εικόνες.

Οι συνεισφορές και οι προτάσεις βελτίωσης είναι ευπρόσδεκτες. Δείτε το [CONTRIBUTING.md](../../CONTRIBUTING.md).
